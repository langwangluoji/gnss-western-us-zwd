# 研究代码

- `engine/tools/terrain_diffusion/`：p14空间场、时序、创新、有向传播、概率与频域实现。
- `engine/tests/`：工程与数值回归测试；主包位于根`src/gnss_field`。
- `europe_transfer_20261126/`：欧洲数据适配、固定CNN参考及基础场比较。
- `europe_vmf3_20261126/`：VMF3背景校正与标准化残差概率生成。
- `joint_fusion_20261126/`：最佳joint均值与GP/Affine/Local融合。
- 其他日期目录：对应已登记研究，不代表当前默认模型。

查看结果从[paper](../paper/README.md)和[实验索引](../experiments/README.md)进入；大型产物在artifacts。
