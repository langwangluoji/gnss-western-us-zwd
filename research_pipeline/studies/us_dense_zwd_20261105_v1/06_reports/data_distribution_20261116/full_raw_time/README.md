# 全部原始数据时间覆盖核验

实际读取全部5084个gzip文件至EOF并解析TROP/SOLUTION数据行，共434058821条小时记录。全部通过gzip CRC和时间格式检查；无重复小时或倒序。统计只验证记录存在，不代表科学变量均通过质量控制。采用原产品名义时间，不进行UTC/GPST转换。

实际总范围：2000-10-30 00:00至2021-12-30 23:00。数据覆盖2000—2021这22个日历年份，但不是22个完整年，也不是每站都有相同长度。站点首末跨度中位数约10.94年。

280个站的文件头首末时间与实际记录不一致，详细差值见header_actual_differences.csv；应使用station_actual_time.csv选站。

全站共同无记录时段（总范围内部）：2005-01-02 16:00—23:00（8小时），2005-08-08 13:00—23:00（11小时），2011-04-19全天（24小时），合计43小时。这里指本地所有文件无记录，不推断缺失原因。

2634个站的实际首末时间跨越2016-01-01至2020-12-31 23:00，首末跨越并不意味着中间无缺测。完整率以该年全部日历小时为分母，2000和2021均含产品总体范围之外的时间。

最初两个未解析文件LA_P、RVO_因站名含下划线；修正规则后重新扫描通过，并已纳入最终统计。使用既有解析器交叉核验AB01的实际首末时间和小时数，一致。

文件说明：station_actual_time.csv逐站首末时间、记录数及内部缺口；station_year_record_coverage.csv逐站逐年；annual_summary.csv逐年站数及95/99%覆盖门槛；hourly_station_counts.csv每小时实际记录站数；global_empty_hours.csv全站空缺小时；summary.json总体汇总。
