# v11：观测汇聚与高差传输配对实验

本轮实践来自v10冻结诊断：模型尚未充分利用局地ZWD，高差插值表现较好，真实目标历史与生成历史不一致。主输出仍为直接地表ZWD，没有固定均值背景或插值教师。

## 配对结构

三组共享v10因果图网络、测站人口、抽样随机种子和训练安排：

- **base**：原41维查询条件。
- **raw**：额外27维观测摘要。时间偏移0/3/6小时与空间带宽50/150/300km的9种组合，每组给出ZWD加权均值、标准差与log支持量。
- **transport**：同样27维摘要，先将条件站ZWD按相对高差变换到查询高程；正尺度L限定1–6km、初始3km。小型边MLP接收距离、高差、粗糙度差、T/P与ZWD，输出有限幅度的值修正。汇聚结果作为输入条件，而不是直接加到最终预测上。

缺测值在汇聚前排除，支持量为0时摘要为0。查询特征只读取条件站；任意一个查询点的摘要不依赖其他查询点是否加入列表。完整网络仍有目标图交互，因此另外检查查询扩展敏感性。

## 共同训练协议

阶段A：base/raw/transport × seed42/17，每组2000更新，条件82站，目标数轮换64/96/137/160。取消真实目标历史，训练和推理都使用缺失目标历史；12小时条件站历史继续保留。AdamW2e-4、100步warmup、cosine降到2e-5、EMA0.99、梯度裁剪1、FP32。

在2018年1/4/7/10月1日前4小时、137验证站、三条件布局上选点。A按macroRMSE；B概率模型按站均衡fair CRPS，同时记录macroRMSE约束。阶段A冻结后扩展至12个月月1日、每段24小时，不用扩展日历重新选点。这些都是已用于开发的2018时段，不称为盲测。

阶段B在A增强编码器两种子均超过base时执行，按两种子平均季度评分选同一个编码器类型。高斯和直接扩散分别3000步/种子，迁移条件MLP、空间层、时间层、查询条件投影和观测摘要；其余生成网络重新初始化。预训练成本另外记录。推理DDIM20，选模K16，目标历史继续缺失。

阶段C保持门槛：概率候选达到相对确定性候选0.2mm点值容忍量并具备概率收益后，才扩展200–500步自生成历史训练。没有通过门槛时保留负结果和阻塞原因，不把单次链路测试当成时序训练成果。

## 数据与记录

复用已激活的允许变量独立QC合同，2016/17共72段训练。只使用训练410与验证137；确认138及C/D标签保持隔离。历史PWV完整率对站点队列选择的影响仍然存在。

每500步保存EMA和原始权重、优化器、固定训练诊断、验证分数。逐步记录loss、训练恢复误差、裁剪前梯度范数、是否裁剪、学习率、尺度参数和耗时；保存每站条件/目标暴露次数。概率固定训练诊断中Gaussian使用解析均值，Diffusion使用K16集合均值，报告时保留这个区别。

## 命令

```powershell
python -m pytest tests/test_observation_transport.py tests/test_terrain_diffusion.py -q
python -m tools.terrain_diffusion.transport_train --variant raw --seed 42 --steps 2000 --out results/20261123_observation_transport_v11/A_raw_s42
python -m tools.terrain_diffusion.transport_probability
python -m tools.terrain_diffusion.transport_evaluate --runs A_raw_s42 A_raw_s17 --all-months --hours 24
python -m tools.terrain_diffusion.transport_report
```

训练输出目录拒绝覆盖。`transport_probability`要求六组A全部完成后才做门槛判断，并将判断写入A_gate.json。所有原始数组和权重留在本机，轻量配置、曲线、指标、报告同步GitHub。
