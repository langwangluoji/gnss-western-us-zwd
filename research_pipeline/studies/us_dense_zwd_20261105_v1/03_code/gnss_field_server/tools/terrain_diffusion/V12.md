基础场每模型族3600秒，种子42/17，各自3折＋最终拟合，共8次拟合，每次450秒。树模型按监控误差提前停止，无需耗满时间。高斯/扩散每种子1800秒实际训练，验证和输出时间另计。记录总耗时与实际更新数；不能保证所有模型恰好在07–08点前完成。

输入：12小时因果观测，空间带宽50/150/300km。每尺度8通道：原始ZWD均值/标准差/支持量、高程传输ZWD均值/标准差/支持量、T/P加权值。高程传输固定3km，作为特征，不作为真值。MLP使用当前、历史均值和首末变化；CNN对三个径向尺度卷积，每小时编码后送LSTM。逐点基础场不包含目标间交互。

空间交叉拟合：150km空间块哈希成三折，物理组保持同折。每折基础模型同时从条件和监督中排除留出折，再预测该折构造残差；全模型单独拟合。50%基础训练事件采用空间空洞选条件，50%随机条件，固定82站；每事件最多128目标，补齐节点单独query_valid标记。OOF条件密度与最终全池有差异，应在报告中检查。

72训练窗口中row模6=5保留作为基础模型监控及概率模型未训练的校正时段；E1207在这些时段再划分树模型拟合/监控。验证137站仅用于季度模型选择和冻结扩展评价。确认138及原C/D标签保持隔离。标准化沿用现有训练410合同，已见训练池标准化不是严格fold-only统计。

高斯残差采用可学习均值/尺度，固定相关核0.7 exp(-d²/(2×50²))+0.2 exp(-d²/(2×150²))+0.1 I，以联合高斯NLL训练。扩散在完整目标残差上进行100步余弦v预测、20步DDIM采样，三层地形图交互；无低维投影。其查询集合依赖仍需诊断，当前不宣称完整生成场具有查询一致性。E1207对同一点所有成员加相同修正，保留集合离散度；不宣称自动保持时间梯度。

选择和扩展均K16，保持后校正输入的有限集合特征口径一致。扩展为2018每月1日24小时×3布局，非完整全年或盲测。随机残差未加入跨小时共享状态，因此时序条件编码不等于已学会随机连续演变。
