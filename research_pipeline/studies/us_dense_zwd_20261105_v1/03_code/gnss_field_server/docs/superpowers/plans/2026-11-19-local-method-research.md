# 本机局部条件场与联合分布小实验

**Goal:** 寻找可复核的条件均值或空间概率收益，保留EDM/GAN后续研究目标。

**Architecture:** 冻结M0；先用A站构造25km格网的局部共享特征，经公共查询算子监督B。局部表示不读取B/C标签，避免现有空间基对开发时刻的暴露。比较零修正、IDW、凸组合、局部创新增益及共享岭回归。若均值泛化成立，再评估小型共享非线性头；概率研究与均值方向分开。

**Tech Stack:** 现有本机PyTorch/NumPy/SciPy，无环境升级，无收费作业。

## 实验契约

- A174仅作条件，B511的2018观测训练。冻结M0以前用过B2016—17，B留组检验增量方法空间转移，不称整链新站测试。
- C2019为已查看开发集。固定288小时先筛查，候选参数在B内锁定后扩大全年。D2020保持封存。
- 使用既有864个2018缓存时刻，整名义7日块留出，按月确保两侧覆盖。空间三折沿用50km组分配。所有拟合、标准化、选择仅在相应训练部分。
- 两尺度75/150km高斯SetConv，截断3倍尺度，保留值与密度。创新统一Z0，先发布格网再按高程查询。
- 小型共享线性头以真实地表站时MSE+显式权重岭拟合。岭强度0.01/0.1/1/10，仅内层天气块选取。零修正和简单对照始终保留。
- 小试使用固定表示基础/扩展两个特征组。扩展加入局部地形差、五变量、密度与交互。所有失败和参数记录，不按C调参。
- 同时报告同站新时段、留组新时段。主要比较相同站时的M0和A-IDW，近站增量按既有S0，100km对照按安全T分别报告。
- 2000次同步7日块bootstrap为开发不确定性描述，多候选选择后区间不作为盲测确认。
