2. 本轮重要发现

   2019主评分人口S0包含76站；代码中的increments表在该人口上有8组、100个0–50 km站对。共同安全粗化模板T进一步筛选后只剩23站，0–50 km比较只有1组、1个站对，同高差不超过100 m的站对为零。

   两张差值表分别评价S0与S0∩T。原始差值评价与原场/粗化场比较应各自保留其人口和作用。共同粗化模板的单站对结果适合局部诊断，其空间覆盖不足以支撑全域细尺度和地形控制结论。

   数值复现与采样扰动结果弱化了灾难性数值失稳的解释。现有数据仍允许表示偏差、噪声拟合与空间泛化不足等解释。第一折候选相对粗化场的差值差为+0.084 mm，探索性区间为[-0.463,0.780] mm，方向未通过与统计证据未定分别记录。

3. 第一项任务，合并零更新诊断

   - [ ] 从标签有效、查询几何、正常A支持、海岸和粗化模板逐层统计站点、站组、站对及站时刻的流失，并出覆盖地图。
   - [ ] 继续使用数据名义小时。既有S0、T和原门槛保持可追溯；任何新算子或人口另建版本并解释科学依据。
   - [ ] 复用已缓存M0和空间基，令d为固定候选修正、P为原100 km粗化算子，比较mu+d、mu+Pd、Pmu+d、Pmu+Pd。分别定位基础场与修正量的尺度贡献。
   - [ ] 导出基Gram谱、正则化有效自由度与采样观测扰动增益，注明采样范围。
   - [ ] 同批加入仅用当期A创新的系数逆算。B当前观测用于评分，和A-IDW、M0及B辅助逆算分别注明信息条件。
   - [ ] A-only诊断在固定评价时刻运行，记录欠秩、零站与支持不足情况。零观测时采用预先声明的零修正输出，并独立记录其发生率。

   验收产物为人口流失表、覆盖图、四场对比表及A-only逆算表。发现人口或查询不一致时，先定位并重算。人口一致但证据覆盖不足时，可以继续小条件头探索，细尺度结论保持未定。多个有覆盖的独立组若持续显示修正高频有害，再以此决定表示改动。

4. 第二项任务，一个单配置条件头短试

   - [ ] 固定M0、每折空间基、s0和站序，定义A值、共同有效mask、四帧粗场、周期量及M0格网的固定汇总特征。特征统计限于允许的训练资料。
   - [ ] 使用零输出初始化的线性128维系数头，首先检验零修正等于M0，最大误差不超过0.001 mm。
   - [ ] 实现时直接输出实际发布系数c，可保证c=0时场等于M0。若复用标准化系数解码器，须处理decode(0)=训练系数均值这一偏移，显式验证零修正初始化。
   - [ ] 直接优化2018拟合B的地表站MSE，锁定系数正则及曲率项。先100步实测速度、显存和恢复行为，再决定是否运行至每折最多1000步，短测计入该上限。
   - [ ] 已查看的2018数据用于开发诊断；早停按完整时间块安排。候选、切片和人口锁定后，评价2019开发切片，所有折均报告，并与M0和A-IDW比较。

   若结果没有可重复的点值方向收益，结束当前单配置小头实验。该结论限定于已测试的表示和条件头。R64或局部基的下一轮实验以诊断结果为依据。

   新ConditionEncoder尚未训练，M0公开接口的特征返回为None。本轮探针采用明确定义的固定输入汇总，特征来源随产物保存。新增提取接口需另外做输出等价验证。

5. 生成模型的后续入口

   点产品继续按RMSE选模，联合概率产品继续按ES选模。原细尺度门槛失败记录保留。后续概率可行性实验另行登记假设、基线和允许结论。

   同时报告概率收益与均值RMSE变化。若需要“点值非劣”的结论，应根据应用误差预算事先登记容差delta，并要求差值区间上界不超过delta。当前缺少该容差的应用依据，先报告指标权衡。

   将全部生成修正乘0.25会使相对修正的协方差缩至1/16。点值收缩结果应通过独立的均值与离散度学习或校准连接到概率模型。K=4成员内强制减均值会改变成员独立性，训练评分需与采样机制匹配。

   现有高斯头为系数对角协方差，经空间基后产生空间相关场，协方差秩至多128。观测噪声和基外残差尚需明确其解释和处理。高斯校准问题须同时检查表示、观测层与分布假设。

   后续顺序仍为确定性条件能力核验、联合高斯、EDM、GAN。进入正式生成训练前，锁定条件与解码器，完成真实路径的显存、耗时、断点和评分短测。GAN的拟合系数标签作为初始化目标，最终评价继续依赖真实独立站。
