# 加宽编码器与独立GAN、Diffusion、VAE实现计划

**Goal:** 在本机验证加宽编码器，训练三类各自完整的条件生成模型并保存可复核指标。

**Architecture:** 原42通道条件与25 km发布查询不变；编码器32/64/128，解码器32/16。先做两个种子的确定性配对对照，然后三个模型分别复制本轮新训练的均值初始化，全部参数允许更新。三个模型之间不共享参数或VAE解码依赖。

**Tech Stack:** 原生PyTorch FP32、现有RTX4060环境；不安装包、不修改旧实验、不提交服务器作业。

**Spec:** 上轮`results/20261123_simple_weather_unet_v02/DECISION.md`及用户本轮“加强编码器，然后接入三类模型完整训练中，进行训练”。

## 范围与资料

用户已确认使用当前A站GNSS及ERA5站位采样变量。复用通过审计的864个训练小时、B357拟合站、B77内部站和B77外层站；实际支持人口另外统计。2018天气留块有18小时跨年缓冲。已暴露外层和C2019子集作为开发比较，D2020封存。这个本机批次训练完整模型，不宣称已使用服务器的2016—2018全部小时。

## 独立模型

- GAN：自身加宽条件编码器、空间潜场与非线性U-Net解码器；真实B站集合与生成格网查询值做条件hinge判别，另用真实站ES/CRPS。
- VAE：自身条件先验、仅训练读取B创新的空间后验、空间潜场和解码器；先做观测ELBO，再用自由先验样本ES/CRPS适配。似然固定3 mm是优化模型假设，不当作实测仪器误差，不在评价集合中补噪声以追覆盖率。
- Diffusion：自身条件编码器与完整格网去噪U-Net，EDM预条件和6步Heun（11次调用）；当前无稠密干净场目标，本轮从自由采样直接用B站ES/CRPS反传完整链。明确命名为“观测评分训练的全格网扩散”，不称为已执行标准DSM。训练与评价采样器相同。

三类均输出完整公共高度格网，再恢复站高。空间潜场候选4×36×24，每小时成员共用完整空间随机状态。噪声按小时、成员及种子确定，拆批和成员前缀保持一致。

## 本机预算与选模

确定性编码器对照：种子42、17，各1000步，batch8，沿用上一轮学习率调度及数据顺序。三类生成模型使用种子42、batch4、K4；VAE观测ELBO600步＋ES1200步，GAN1600步，Diffusion1000步。本轮基准测量后，累计本机墙钟上限设为60分钟，包含短测、训练和评价；不足时保存独立预算状态，不伪造完成。此资源调整在正式生成训练前作出：首轮测得更新耗时VAE0.75秒、GAN0.25秒、Diffusion1.17秒，估算更新约49分钟，另需评价时间；这不是依据精度扩大科学步数。

生成训练用学习率0.0002、weight decay0.0001、余弦下降至0.00001、梯度裁剪1。ES和CRPS采用无偏成员间估计。每200步固定24个内部天气时刻、K8评价；第200步前仅记录基线，不将未更新的初始化作为生成模型最终候选。点产品按站宏RMSE，联合概率产品按预登记200 km站组宏ES，分别保存；最终K32重新评价固定144小时与C48小时，记录抽样规模限制。

## 关键解释

固定站监督不能唯一确定无人观测区域；观测评分训练不消除这一点。参数增多不保证泛化改善，较大编码器即使没有点值优势，也要按完整模型对照如实记录。生成模型的点值产品与概率产品不可跨检查点拼接指标。
