**Goal:** 在用户本机完成VAE后期ELBO、GAN当前对抗项、Diffusion无偏均值MSE的配对验证，以实际指标作结论。

**Architecture:** 保留现有三类网络，新增独立实验入口及无偏均值目标；不改变上一批已锁定训练源码和权重。

**Tech Stack:** 现有PyTorch、RTX4060，FP32训练/采样、FP64指标与数学测试，不安装依赖、不提交服务器作业。

**Spec:** docs/superpowers/specs/2026-11-23-generator-mean-control-design.md。

## 执行记录

Ruling: 当前工程非Git仓库，采用新的实验命名空间和哈希锁隔离，不修改已锁定旧训练路径，不创建伪提交。

Ruling: 用户本轮要求完成环境验证后才给结论，因此监督到六臂端点评价完成，不把已启动后台队列作为完成。

2026-11-23执行：三家族原目标更新路径的模型及判别器参数差均为0；计时锁定每臂300步、Diffusion均值约束0.1。VAE和GAN两臂已完成，Diffusion运行中。

审阅记录：独立复核确认训练配对、角色隔离、U尺度与采样维度正确。复核指出确认判据不可只检查复验RMSE方向、忽略概率评分守护；已补失败后通过的回归测试，K64、适配seed17、独立噪声都需通过完整点方向判据。补充parent源码校验和旧joint_best比较；核心训练锁未修改。

Ruling: GAN生成器使用新增阶段5e-5→1e-5，判别器保留原学习率2e-4及weight decay0.01；两个GAN臂保留相同判别器更新，确保干预仅是生成器对抗系数。

Ruling: 两种适配种子的复核不等于完整链条从头训练的独立种子实验。K32后无门槛通过的家族不追加无目的训练，交付未观察到足够收益的结论。

执行完成：主六臂及VAE/GAN的适配种子17配对，共10臂、3000次新增更新完成。K32全部端点、VAE/GAN独立噪声和K64、旧point/joint检查点比较均完成。27项相关测试通过；实际K32→64成员前缀站值最大差0.0000610 mm。累计实验运行1303.235秒，约21.7分钟。详见results/20261123_generator_mechanism_validation_v01/VERDICT.md。

结论：GAN后期关闭对抗项有可复核概率收益，但点值尚未超越原point_best；VAE取消后期ELBO只改善相对继续训练的概率评分，未超过原入选产品；Diffusion的本配置无偏均值MSE未提供收益，不采用。未训练的双支路架构不标为可行。

追加旧优选采样复核完成：GAN相对旧joint_best的ES改善在K32为1.002%、K64为0.995%，独立噪声为1.591%；不足以认定稳定通过本轮替换门槛，保留原有产品。它相对继续对抗训练的后期适配收益仍通过两适配种子、独立噪声和K64复核。辅助评价曾因263字符临时路径超过Windows长度限制而中止，已缩短本轮辅助文件名恢复，原权重和科学配置未修改，额外耗时计入预算。
