# 本机简单U-Net：现有气象变量的配对验证

2026-11-23。用户授权本机小实验，先检验简单U-Net，再决定是否扩展编码器。原实验及服务器作业保持原状。

采用原生PyTorch与本机RTX4060，独立试验脚本，从头训练。气象来源使用现有GPAC-Repro产品在A站保存的ERA5温度、气压、Tm和PWV；用户已确认“就是现在这个数据”。这些是气象产品站位采样，不能称为独立完整气象格网。

配对比较：GNSS＋地形的小U-Net，以及增加四项气象变量的同规模U-Net。保留四帧0/6/12/18小时，144×96完整发布格与已有公共高度查询。所有模型从A站IDW粗格起步，零初始化改正头；不使用历史学习底座、岭回归、空间基或权重。气象删除组保留同一输入宽度，将对应通道置零，使初始化和参数量相同。

固定种子42及17，每组最多1000次更新，AdamW、学习率0.001随本轮预算余弦下降至0.00002，batch8，宽度16/32/64、双层卷积及GroupNorm/SiLU、镜像U-Net。以内部B站验证选模，C/D不参与选模。暂停文件为结果目录内PAUSE；每100步保存状态与曲线。

B站按50 km空间组划为约70%拟合、15%内部选模、15%最终诊断，种子20261117。2016—2018每月抽取24个训练时刻；2018每月1—3日及16—18日分别用作内部与最终天气留出，训练排除两侧18小时。候选小时与站组在读标签前锁定。输入归一化仅来自A训练时刻。内部选模取留站且留天气的站宏RMSE。

最终分别报告：新站同训练天气、新天气拟合站、新站新天气；C2019固定月度小时可在B选模结束后作开发确认，D2020保持封存。比较A粗格双线性、A直接IDW格网、ERA5站位PWV/Tm换算插值和两组U-Net。全图先发布再统一站高查询，非有限预测触发失败。

输出锁文件、数据来源审计、训练日志、权重、逐站预测、损失/验证曲线、误差与场图。月份事件块置信区间用于本轮小样本诊断，区别于完整全年7日bootstrap；若收益方向不稳定，不扩展编码器。候选参数与优化预算已在训练前登记，不根据最终留出结果反复调参。
