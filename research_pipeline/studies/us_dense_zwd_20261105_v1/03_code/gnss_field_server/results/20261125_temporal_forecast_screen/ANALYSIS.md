# 首轮时空预报实验：结果解释与后续决策

2026-11-25。真实本机双种子筛查完成26个配置拟合；每个配置先2016–2018内层拟合，再按2019选择的更新数从头在2016–2019事件上重拟合。600更新为本机筛查上限，不能据此认定收敛。

## 最有用的结果

同一2020抽样开发人口上，空间持久性宏RMSE为15.163 mm，当前帧模型14.203 mm，72小时因果Transformer为13.914 mm。Transformer相对当前帧模型改善0.289 mm（约2.0%），相对持久性改善1.249 mm（约8.2%）。按24个天气周、1000次配对bootstrap，前者差值95%区间为[-0.458,-0.130] mm。

该区间针对本次事件人口和配置比较；不是多重模型搜索后的独立确认。隐层宽度固定但参数量不同，后续参数匹配和完整天气过程仍需验证。

Transformer的12/48/72小时平均宏RMSE分别13.977/13.972/13.914 mm。增加到72小时带来小幅改善；不能从这三个点推断“一周一定更好”。GRU的48/72小时结果几乎相同，表明该配置较早历史对最终状态贡献很小，应检查有效记忆与梯度，再决定是否增加长度。LSTM48小时14.262 mm，与当前帧模型接近。

## 快速变化尚未解决

当前帧模型的小时增量宏RMSE为5.982 mm，72小时Transformer为6.001 mm。均值预测改善尚未转换为小时变化改善。下一轮优先检验增量目标、空间状态传播和概率轨迹，而非只继续增加上下文。六小时模型联合输出是确定性均值序列，尚不能称为已验证的联合概率生成。

## 本轮实现范围

- 连续数据：2016–2020共43,848名义小时、训练池410站；2020验证池137站。开发抽样有135站有效，评分记录108,954个（包括布局重复）。
- 变量：允许的ZWD/T/P独立记录QC、静态地形、Natural Earth 1:50m海岸距离。时间基准保持产品名义小时，未假定UTC/GPST。
- 模型：8×8固定空间载体、16通道空间卷积/下采样/跳连、精确查询点IDW持久性跳连；时间hidden=64，GRU/LSTM两层，Transformer两层四头。
- 海岸输入为C1查询点静态特征；C2边消息、完整地形FiLM、p14权重迁移尚未实施。
- 历史长度表示动态观测窗口；共享最长窗口计算的age元数据。当前帧对照也有可用性元数据，不称严格无历史观测任务。
- p14约10.8mm来自2018空间重建合同；本轮是2020未来预报，不作跨合同排名。
- 26组是26个“模型×长度×种子”配置，每组包含内层拟合与从头重拟合，共52次训练过程；另有smoke流程。

## 下一阶段顺序

1. 完成C0/C1/C2海岸消融与更细空间载体比较，明确空间编码与时间编码的贡献。
2. 将12/72/168小时在同一锚点交集上比较，加入参数匹配；用分块时间输入控制显存和计算量。
3. 针对夏季、远支撑和小时增量加强训练目标，比较显式状态变化与空间传播。
4. 生成可追溯的空间折外基础场残差，先验证观测空间到潜场的查询重构误差，再启动同条件Gaussian/Residual Diffusion。
5. 概率阶段独立评价CRPS、覆盖率、站对差值及小时增量联合分布，保留成员shuffle对照。

全阶段结果见[REPORT.md](REPORT.md)；指标逐项重算见`verification.json`，本轮已保存预测的宏RMSE复算最大差为0。

验证：全工程568项测试通过，新工具与固定支撑相关21项通过。训练后的Transformer72 seed42查询137/64点最大同点漂移5.96e-6 mm，见`query_consistency.json`。权重与大型预测数组保留本地。
