二、当前函数表示与代码实质

Z0(t,x)=mu0(t,x)+s0 Phi_theta(x)c(t)。s0是2016–2017 B训练标签的Z0标准差，冻结。Phi由x、y、高程及6档x/y正余弦特征组成27维输入，网络27→256→256→128（SiLU，末层线性）。每列按固定陆地格网RMS归一化，无显式正交或局部支撑约束。

表示学习中，对每小时用拟合组B站的当前残差逆算c，FP64求解以下目标，再对Phi反传：
mean((H_fit c-e_fit/s0)^2)+lambda mean(c^2)+0.001 mean((L_support Phi c)^2)。H=diag(exp(-Hstation/3000)) Q Phi，lambda原值0.01。L只在支持域完整五点模板上取离散曲率。求解正则项为(lambda/R)I，与mean(c^2)一致。当前曲率针对Phi c；这是代码实质。

三折按50 km密集物理站组划分，均用2018年各自的拟合组学习空间基3000步（有效批16小时），外层整组留出B站只评分。每小时至少R+8个合格拟合站。M0用过这些物理B站的早年资料，故这是“残差表示层内部的2018组留出”，不能当成整个M0链条的独立物理站评价。

三、服务器三折结果与停止原因

每折576个2018分层时刻。共同细尺度评分位置分别52/55/62站，29236/30911/34482站时。表内是共同位置的站宏RMSE：
折1 M0 7.027791，原空间基逆算10.486632，其完整重建场降100 km后回采样9.181917；
折2 M0 7.010206，逆算12.301809，粗化10.006684；
折3 M0 7.186417，逆算9.611086，粗化8.380918。
0–50 km组宏Z0站间差值RMSE，M0/逆算分别为11.530093/13.404780、10.693740/14.582903、10.991758/12.583973。每折有7/7/12个有效密集组、25/39/51个站对。
全部576时刻的H均满128秩（数值阈值s_max×1e-6），因此原门槛的observable_fraction=1。数值满秩不等于稳定可辨识。
预先设置的表示门槛要求每折同时满足：点RMSE优于M0与自身粗化场，0–50km组宏差值RMSE也优于两者，至少95%时刻rank≥64。三折都失败。Slurm队列按门槛停止，最终空间基和各预测头均未运行。服务器已停止本批GPU任务。
