# 本机空间算子探索

目的：检验平滑聚合丢失方向与高差信息、固定底座及天气地形交互是否限制剩余点值收益。用户授权大胆本机探索；本批为研究spike，不改生产模型和环境，不提交服务器。

保持上一批576训练小时、48内层小时、原288外层锚点、物理站组、地表标签与公共格网查询。B2018含历史暴露，所有结果称增量开发。C2019、D2020不读取。

三类有限候选：

1. 69维线性对照增加8个预定义天气幅度×源高差/地形起伏/站距交互项。标准化只使用训练小时。ridge强度保持1e-4、0.01、1。
2. A创新量在50/100/200 km、无高程屏障/750 m高程核上聚合；各输出常数、东西、南北、高差四个矩，共24维，追加原69维。允许有符号矩，检验IDW式平均丢失方向。相同ridge。
3. 公共格点定义高斯空间核，使用真实A查询矩阵构建Kobs=QA Kgrid QA^T。水平100 km，高程核无/750 m，噪声比0.1/1，共4候选；逐小时仅从有效A站创新同化。整体幅度在拟合B上解析估计并截至[0,1.5]，内层选型。

所有参数仅拟合训练B×训练时刻；A条件不读B。候选与零改正由空间×天气内层选定，保存选择锁后才能打开本轮外层分数；不按外层调参。原外层已多次暴露，本批不能宣称新盲测或确认性显著。

沿用每折内层至少0.5%改善、外层同向、短距离变化与线性对照核查。筛查全失败时不扩大对应模型，重新向Pro讨论。若某类有稳定信号，再登记匹配的浅层神经算子训练或新天气确认；概率收益和点值收益分别评价。

每类先短测；全批本机目标20分钟级，实际耗时记录。缓存可复用，阶段完成后写小文件状态。仅研究spike，不承诺长期断点兼容。保存输入身份、来源代码、模型系数、内层候选、外层锁定评分和诊断图。
