# 核改正的天气门控小试验

前三类筛查已有结果后追加的探索阶段，单独登记，不与先前候选伪装为一次预登记搜索。三类完整结果和选择锁保持原样。

选用各折由原内层选择的高程核分支，冻结核长度、噪声及训练B拟合的全局幅度。仅训练一个8→16 SiLU→1门控，输出幅度1.5 sigmoid(logit(alpha0/1.5)+MLP)，末层为零。输入依次为当前A场幅度、当前与前6小时湿度幅度差、两尺度源高差、地形起伏、最近站距、年周期两量（均在格点定义）。不改站高恢复。

训练与前批同576小时、batch8，最多14遍1008步；恒定LR1e-3、AdamW weight decay1e-4、裁剪1。至少4遍、连续4次正式评价无改进早停；每72步评价，200步启动检查不选模。raw选模，EMA半衰期72步仅诊断，step0核方法保留。

两折分别与固定幅度核对照，依内层选择，选型锁定后才打开该阶段外层分数。目标是判断天气自适应能否在已有空间核收益上增加稳定收益；失败则保留简单核，不扩大门控网络。

本机spike，不启动服务器。原B2018外层已有暴露，新的候选仍为增量开发。完成后可锁定原核与门控各折产品及48个固定C2019时刻（每月7日0/6/12/18时），再进行一次开发确认；先锁候选与时间，再读C标签。D2020保持封存。
