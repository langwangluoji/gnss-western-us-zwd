# 数据量试验结论

普通Diffusion Transformer在当前配置下不适合直接增加同样的训练预算。72段训练从1500增加到3000步，两个种子仍分别由inner选择第300/600步，固定评价结果与v07完全一致。原训练轨迹复现误差为0。

把训练片段增加到144段、保持3000步后，月27日宏RMSE为9.2778/9.7595mm，原72段为9.1606/9.1594mm。两种子平均综合分在月27日变差；在月22日略改善。seed17的区间宽度、覆盖率和部分概率评分有改善，不能把此结果概括为增加数据对所有指标无效。总体没有稳定的候选替换依据，仍保留原v04约9mm结果，未达到8mm。

此次增加的是2016/2017的训练时段，A174稀疏观测网及评价人口保持固定。每次更新batch不变，更多片段意味着每片段访问次数变少。结果只覆盖本次日期扩展、学习率、选择规则和24维空间表示，不能外推到全量多年度训练的最终上限。

综合v07/v08：优先保留普通DiT作为后续去噪器候选，暂不扩大稀疏专家。更值得检验的下一方案是多尺度残差表示与观测空间概率损失，让24维子空间之外的残差也进入生成分布；低秩扩散与原随机场的互补组合可作为对照。上述表示改造尚未实施，不把它写成已验证有效的方法。
