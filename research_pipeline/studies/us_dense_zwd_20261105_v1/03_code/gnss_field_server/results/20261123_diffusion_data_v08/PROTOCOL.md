# Diffusion Transformer：样本量与训练步数

用户允许调整输入数据量。先调整训练时段数量，保持A174输入站数、6h暖启动＋24h序列、输入变量、24维残差空间、背景、内层与外层人口不变。

v07四候选开发筛查中普通Diffusion Transformer综合分较优，因此进行适应性后续试验；不称独立确认。

- 原训练：2016/2017每月8、18、25日，共72段。
- 加倍训练：保留原72段，追加2016/2017每月4、12、22日，共144段。均从现有数据包读取A输入和B训练目标；C/D不读取。新时段不与原train/inner/outer/confirmation/reserved窗口重叠。
- 两种子42/17；对照为原72段从头训练3000步，实验为144段从头训练3000步；另引用已锁v07原72段1500步作为步数对照。初始化、优化器、batch128、噪声/抽样生成器、每300步inner选择规则、20步DDIM全部复用。
- 残差解码基与标准化沿用v07。新增时段B-fit系数仅使用新增时段B-fit监督计算，再转换到原标准化；A条件、背景和v04 ridge全部冻结。保持扩散目标坐标系不变。
- 原72段前1500步的内层轨迹与v07自动核对。四次训练完成后评价固定月22/27日、K64/K128，报告原模型与v07对照，保存负结果。
- 此次增加样本量和更新次数并未修复24维子空间只解释约18%训练残差平方误差的结构限制。90%覆盖率、CRPS及增量评分必须与RMSE一起评判，未证明8mm可达。
