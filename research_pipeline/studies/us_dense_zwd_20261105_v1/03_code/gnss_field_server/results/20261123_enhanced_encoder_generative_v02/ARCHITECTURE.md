# 加宽条件编码器及三个独立生成模型

2026-11-23，本机完整网络训练批次。当前输入仍为用户确认的现有A站GNSS与ERA5站位采样气象量，不另称为独立完整天气格网。

## 共同输入和发布

42通道：四帧五变量粗格20通道、四帧支持标记4、四帧GNSS数值/密度散布8、地形与位置6、时间周期4。发布144×96公共高度格网；预测站值统一为双线性插值后乘exp(-H/3000)。不使用历史学习底座或空间基。

## 编码器配对对照

|层|上一轮小模型|本轮加宽模型|
|---|---|---|
|编码1，144×96|42→16→16|42→32→32|
|编码2，72×48|16→32→32|32→64→64|
|编码3，36×24|32→64→64|64→128→128|
|解码2，72×48|拼接后→32→32|拼接后→32→32|
|解码1，144×96|拼接后→16→16|拼接后→16→16|
|输出|16→1改正|16→1改正|

每层3×3卷积、GroupNorm、SiLU，平均池化下采样、双线性上采样和skip连接。解码输出宽度保持32/16；编码增宽导致拼接输入宽度相应变化。小模型124,529参数，加宽均值模型375,473参数。

## 三个完整分支

三个模型分别拥有自己的加宽条件编码器和解码器，复制本轮种子42确定性模型作为初始化，然后全部参与相应模型训练。VAE不是GAN和Diffusion的依赖。复用的是纯网络代码与数据契约，不共享可更新参数。

### GAN

4×36×24空间高斯潜场经1×1卷积投影到128通道，加入条件编码器末层，经过自身非线性U-Net解码器生成场。训练判别器读取相同B站位、相同mask的真/假查询值，以及仅由输入构造的条件和地理位置；使用两头站间注意力与池化，学习观测集合依赖。生成器损失是ES＋0.2CRPS＋0.05对抗项，各评分先以10 mm缩放；判别器hinge损失。

### VAE

自身条件128通道经1×1卷积产生4通道均值及4通道log标准差，定义条件先验。训练后验额外接收拟合B站创新经统一查询权重的散布图及密度；后验输入不经过推理条件接口。600步观测ELBO后，用自由先验样本ES＋0.2CRPS适配1200步，保留0.1ELBO正则。固定3 mm训练似然尺度是优化假设，不宣称仪器误差标定，不额外加入评价集合以改变覆盖率。

### Diffusion

自身加宽编码器每小时提取一次条件；带噪格网另用16/32/64三层编码器、噪声级MLP及轻量解码器去噪。EDM预条件、sigma_data0.5、sigma_max2、sigma_min0.02，6步Heun共11次网络调用，从完整1×144×96白噪声格网生成空间残差，加到自身可训练均值上。

当前没有稠密干净目标，因此本轮是“完整采样链＋真实B站ES/CRPS”的观测评分训练，不执行或声称已执行标准全场DSM。网络、求解器、初始噪声均保留真实采样过程，梯度穿过全部11次调用。固定站监督仍不能唯一约束无站区域；空间结构效果由独立站组与发布格检验。

## 评价和资源

两个独立选模产品：点值最优、站组ES最优。分别报告各自同一检查点的RMSE、MAE、偏差、CRPS、ES、VS、区间覆盖及宽度；加入逐站打乱成员的空间依赖对照。VAE最终使用先验自由采样，不用后验重构代替部署结果。

本轮沿用864训练小时和之前已暴露的开发人口；没有新增盲测，D2020继续封存。局部训练阶段通过后，服务器全2016—2018小时及更大集合成员数需要另外锁定数据与预算。本机顺序执行，60分钟总墙钟门槛，失败、暂停及预算耗尽分别记状态。
