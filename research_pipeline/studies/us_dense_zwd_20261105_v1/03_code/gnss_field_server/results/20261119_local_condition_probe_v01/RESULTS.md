# 本机条件修正小试结果与模型判断

本次在2026年11月19日完成，使用RTX4060 Laptop GPU。M0为冻结的5000步EMA，空间基复用服务器三折各3000步的R128权重。主流程包含2019基础场切片计算、短头训练和最终开发评价，耗时约122秒；前置诊断另见diagnostics.log。

1. 已执行的模型改动

   新增独立线性条件头，2720维固定条件汇总输入，输出128维实际残差系数。输入为174个A站的标准化五变量与共同有效标志、四帧粗场的4×4固定池化、4个周期量及M0场的4×4固定池化。条件构建读取A站及允许辅助，B站仅作为损失标签。

   输入汇总的标准化参数仅由本轮648个训练时刻估计。另有216个完整七日块隔离的头部开发时刻。864个时刻均属于已查看的2018探索资料；空间基此前使用过拟合B组在头部开发时刻的标签，因此该划分衡量固定表示下的头部时间泛化。

   头部直接输出实际系数c，权重和偏置均零初始化，发布场为M0+s0 Phi c。初始场严格等于M0。使用真实拟合B站的地表MSE、系数正则权重1和曲率权重0.001，AdamW学习率1e-4，warmup100步，余弦时长1000步，EMA0.999，有效批32小时。

   每折科学训练上限1000步，三折均因开发指标连续三次未改善在800步早停。另有用于精确恢复验证的工程更新，和科学训练记录分别保存。

3. 零更新诊断

   原始2019资料有110个有观测的C站；有效查询几何保留103站；正常输入支持保留76站、100个近站对；安全粗化共同模板进一步保留23站、1个近站对。详细站时与组数见population_audit.json及station_retention.csv。

   在864个2018探索时刻的共同细尺度位置上，保留M0细场时，只粗化残差与保留残差的差别较小。粗化M0本身显著增加点误差。新增残差高频的影响存在折间差异，当前证据不足以把所有误差归因于新增高频。

   陆地基Gram谱的参与率秩约36.3–37.2，采样正则化有效自由度约94。该能量集中指标与数值秩分别定义，其数值不直接给出应选的网络秩。完整谱和采样结果保存在inverse_diagnostics.json。

4. 模型是否需要改变

   M0继续作为冻结基础场。本次验证的全域空间基与线性条件头组合尚未提供新增点值收益，因此按本轮停止规则结束该单配置点修正试验。

   下一轮模型改动优先围绕残差表示的空间泛化和条件学习设计。一个可检验的方向是让表示学习在训练内部采用空间组支持集与查询集，按留组重建表现约束表示；局部多尺度表示也是待诊断支持的候选。上述改动仍需新方案和对照验证。

   现有结果限定于本轮648小时、单配置线性头及已有空间基。条件编码器和非线性预测头的能力、概率残差的可学习性仍需分别检验。EDM与GAN的均值、离散度和联合空间结构应按双轨评价。本轮没有产生EDM或GAN的新精度结果。
