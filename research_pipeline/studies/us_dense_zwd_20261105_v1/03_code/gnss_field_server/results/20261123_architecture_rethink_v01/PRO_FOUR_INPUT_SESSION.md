## 本轮直接代码核查

`src/gnss_field/generative/data.py` 的 `INPUT_VARIABLES` 定义五变量为 `Z0_mm, temperature_k, pressure_hpa, tm_k, era5_pwv_mm`。

`FullFieldData._build_compact` 先读取四帧 `store.context_values` 的A站数组，再对各帧全部五变量按站点几何权重生成 `coarse`。这条生产路径的粗格为A站插值表达，尚未成为新的独立气象格网分支。原有气象辅助量的存在不等于已经接入独立完整天气格网。

## 完整回复摘要

已逐段读取完成答复，并在末尾确认 `FOUR-INPUT-DESIGN-END`。以下为摘要，不是逐字转录。

1. 建议采用直接四输入条件VAE作首个机制验证模型，同时独立实现观测集合GAN与完整格网Diffusion。理由为训练似然清楚、单次前向采样较省；没有声称VAE精度已优。
2. 建议独立气象先考虑ERA5模型层温度、比湿、层系数、地面气压及位势，积分构造ZWD背景与Tm，再加2m温度、地面气压、TCWV、10m两方向风，共七个条件量；变量可用性与剖面转换需要实际审计。
3. 建议气象56→16→16、IDW20→8→8、站点共享MLP6→16→16后按四帧散布成68→16→16、地形8→8→8。将IDW与站点合并成16通道，再与气象16、地形8合成40→32。距离和密度只表达几何支持，不自动等于校准置信度。
4. 建议轻量五尺度主干32/64/96/128/192，对应144×96至9×6；每级一个两层3×3卷积残差块，GroupNorm、SiLU，镜像上采样与skip连接。
5. VAE用4×36×24空间潜场，条件96→8产生先验参数。B创新集合只供训练后验，经32→48→64并与条件96拼接，160→96→8产生后验参数。只在部署先验样本上评估。空间潜变量尺寸是设计假设，不是有效秩证明。
6. GAN用独立生成器与空间潜场；判别器比较相同B站位和mask下的真/假观测集合，建议64维站特征、一层2头站间注意力、池化、32→1，hinge对抗加站组ES。若输出无测量噪声场，判别前须经过匹配观测误差模型。
7. Diffusion独立去噪器接收32通道条件与一个带噪残差通道；噪声级嵌入32→128→128。完整场DSM从明确的稠密参考减背景得到干净残差；真实B适配可通过自由采样的ES/CRPS。推理不经过VAE。
8. 建议4060先做48×48、含山地和观测空洞的四季小范围，两个种子及确定性对照；三模型享有同一稠密参考。输入消融和优化对照分开，后续单张A800全域训练。
9. 三模型统一比较点值、近站差值、CRPS、ES、VS、覆盖与宽度。均值对齐仅作解释性诊断，不作为可部署模型排行榜。

## 独立判断与待解决项

- 同意优先验证四路条件与紧凑主干。VAE首跑是工程顺序，GAN与Diffusion仍是完整研究对象，三者尚无新输入条件下的优劣证据。
- Pro新公式为地表发布场Y=W(x,H_DEM)+r，站点查询为W(x_i,H_i)+Interp(r)。它不等于只重载单张Y再按旧算子查询。若采纳，发布包必须保存可重建站高背景的附属资料，且所有对照使用同一新算子；不能直接满足旧单场重载验收。首轮建议沿用已锁查询，把高程变化单列实验。
- Pro的4×36×24潜变量有3456个数，超过每小时B站标量监督数。非线性卷积与KL可以施加先验，但不能据此认为潜变量已由观测识别。需检验KL空间分布、先验/后验差、潜变量扰动与留组泛化；潜变量规模尚不锁定。
- 七变量与56通道只是候选。先查验ERA5原生尺度、变量和现有资料，不能将ERA5插值到25 km称为获得25 km独立细节；人为粗化到100 km与真实独立产品的降尺度任务分别登记。
- 只让Diffusion使用稠密参考、GAN/VAE仅用站点，会混入训练信息差异。公平三模型主比较给三者同一参考资料与真实B适配；无稠密资料时的站点VAE/GAN另列资料条件。
- 普通DSM缺少干净场目标不等于所有可能的扩散参数化训练在数学上均不可行。若研究只靠观测ES端到端训练采样器，须单列为观测评分训练路线，验证完整采样梯度和成本，不冒充已具备标准全场去噪监督。
- 新方案尚未训练或验收；本轮没有改变服务器作业。
