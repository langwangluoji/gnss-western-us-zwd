# 完整条件VAE、GAN与Diffusion：架构及全量训练协议

三类模型从同一份融合背景场出发，学习空间连贯的随机残差，输出144×96格网的统一高程ZWD。25 km表示输出间距。研究同时比较点值精度、站间变化、边缘概率与空间联合分布。

本轮Pro两轮讨论全文为`PRO_REVIEW_FULL.txt`与`PRO_FINAL_REVIEW.txt`，最终建议已取回。模型采用新独立模块，不复用旧生成器权重。冻结背景资产的历史路径和SHA256保留在机器清单，正文统一使用功能名称。

## 数据与监督

输入为174个A站的五变量，当前及此前6/12/18小时四帧，加地形、位置和周期信息。粗条件明确是A站IDW场。训练使用2016—2018全部合格小时的511个B站；2019年C站用于开发；2020年D站封存。

训练原始26,304小时，四帧历史及真实站支持审计后26,262小时。原始B有效站时刻13,132,476；各小时实际可监督站数由当前输入支持和固定查询几何共同确定。至少4个合格B站才训练。训练固定参考站数442，用于似然与KL共同归一。

全年2019继续采用76个可评分站、642,258个站时刻的原锁定清单，覆盖原始8,760小时；空评分小时单独计数。576小时开发子集只按原日历的月份×名义小时、时间顺序约1/3和2/3位置确定。

融合背景由冻结站点重建网络、网络与A站IDW约73.9%/26.1%混合、训练资料拟合的多尺度高程相似创新量岭回归校正组成。它是三模型相同的输入及比较对象。

训练监督来自真实站点；不存在独立密集高分辨率场真值。VAE后验样本是GAN和Diffusion的潜空间预训练目标，模型精度由独立C站评价。空间零空间的细节用场图和功率谱诊断，面积平均精度不从独立站成绩直接推断。

## 公共条件编码器

网格37通道：四帧五变量20、四帧有效率4、地形高程与双向坡度3、XY2、陆地1、融合背景1、站距密度2、周期4。站点31维：四帧五变量20、共同有效标记4、XYZ3、周期4。

| 模块 | 操作 | 输出 |
|---|---|---|
| 网格入口 | 3×3卷积37→32，残差块 | 32×144×96 |
| 编码一级 | 步长2卷积32→64，残差块 | 64×72×48 |
| 编码二级 | 步长2卷积64→96，残差块 | 96×36×24 |
| 站点入口 | 31→64→64，SiLU | A×64 |
| 几何注意力 | 网格查询、站点键值；64维4头；距离及高差偏置 | 96×36×24 |
| 编码三级 | 步长2卷积96→128，残差块 | 128×18×12 |
| 编码四级 | 步长2卷积128→192，残差块 | 192×9×6 |
| 全局条件 | 最深层空间平均 | 192维 |

残差块为GroupNorm（8组）→SiLU→3×3卷积→GroupNorm→SiLU→3×3卷积，与必要的1×1捷径相加后除以√2。全缺站使用专用空token。无BatchNorm。

## 非线性场解码器

每小时、每成员共享一个全域潜变量z，主配置64维；128维通过B训练内部诊断决定。它控制整张场的共同变化，不是逐站独立噪声。

| 层 | 输入及操作 | 输出 |
|---|---|---|
| 潜变量投影 | R→256→1728，重排 | 32×9×6 |
| 最深解码 | 拼接192通道条件，残差块224→192 | 192×9×6 |
| 上采样一 | 双线性上采样，拼接128通道，残差块320→128 | 128×18×12 |
| 上采样二 | 拼接96通道，残差块224→96 | 96×36×24 |
| 上采样三 | 拼接64通道，残差块160→64 | 64×72×48 |
| 上采样四 | 拼接32通道，残差块96→32 | 32×144×96 |
| 场输出 | 1×1卷积32→1，乘10 mm并加融合背景 | 1×144×96 |

每层由z的线性映射产生FiLM缩放与平移。输出层小幅非零初始化。查询先对统一高程场双线性插值，再乘exp(−H/3000)恢复地表ZWD。

编码器1,663,304参数；解码器2,328,033参数。以下计数均为64维配置。

## 条件VAE

VAE（变分自编码器）训练时利用真实B站构造近似后验，部署时从只依赖输入条件的先验采样。

后验把32通道查询特征映射为64维，拼接站点残差1、XYZ3及有效标记1，共69维；69→128→128后做掩码均值和最大值池化，得到256维，再拼接192维全局条件：448→256→2R，输出均值和对数标准差。条件先验为192→256→2R。对数标准差限制在[−6,2]，潜变量经重参数化后进入场解码器。完整VAE共4,249,065参数。

目标为真实站高斯工作似然与KL(q‖p)之和：似然先对有效站求和、KL对潜维求和，两者共同除固定442，再按小时平均。表示训练前10%更新进行KL预热，之后β=1。完整VAE微调保留ELBO并加真实站能量评分ES。

独立有效差异尺度σ_eff候选3.18/6.36/12.72 mm，通过B训练内部物理站组折和分离天气面板的先验CRPS选择，NLL作同分次序。该尺度表示未解析差异，不解释为实测GNSS仪器噪声。观测概率产品在地表查询后加一次独立差异项；发布场成员不包含这项站点独立噪声。

## 条件GAN

GAN（生成对抗网络）的完整推理为条件编码→噪声潜变量生成器→场解码器→地表查询。

标准高斯噪声R与192维条件拼接，线性映射至256；四个256维LayerNorm/SiLU残差MLP块，通过噪声与条件FiLM调制，最后256→R。生成器1,139,008参数。

潜变量判别器为(R+192)→256→256→128→1，LeakyReLU0.2，共164,609参数；使用WGAN-GP（梯度惩罚10），每次生成器更新对应3次判别器更新。无BatchNorm，当前实现不使用SpectralNorm。

完整模型优化阶段采用真实B站观测判别器：每站32维条件、残差及XYZ进入36→64→64编码；掩码均值/方差128维，加四个距离箱各64维站对特征，共384维，经384→128→1输出。每箱按固定物理顺序取最多256对。观测判别器62,465参数。对抗项与ES的生成器梯度尺度在首步及每100步记录；对抗项超过ES梯度10倍时停止，保留诊断，不自动改变锁定权重。

## 条件潜空间Diffusion

Diffusion使用EDM（Elucidated Diffusion Model）在潜空间去噪。训练目标为冻结VAE近似后验抽样，按训练期逐维均值及标准差变换；这是逐维标准化，不是全协方差白化。

R维带噪潜变量→256。噪声尺度的32组正余弦产生64维时间嵌入，与192维全局条件拼接，经256→256→256编码。四个256维LayerNorm/SiLU残差MLP块由时间及条件FiLM调制，末端256→R。去噪器1,221,952参数。

标准EDM预条件，σ_data=1，logσ服从N(−1.2,1.2²)。去噪预训练每样本一次网络调用；推理及真实站ES微调均用18级Heun、35次潜变量网络调用，完成潜变量后每成员只解码一次完整场。

## 两层比较与全量队列

第一层比较共享且冻结的条件编码器、解码器和误差核，检验VAE/GAN/Diffusion先验差别；三者均获得真实站ES微调。第二层为三个独立完整模型，允许各自更新条件编码器、解码器及先验。第二层结论对应完整体系，不单独归因于先验。解码器更新后不再用旧后验缓存继续DSM。

| 阶段 | 数据遍历上限 | 每更新小时数 |
|---|---:|---:|
| 确定性场对照 | 10 epoch | 8 |
| VAE表示及先验 | 30 epoch | 8 |
| 后验缓存 | 1遍全部训练小时 | 8 |
| GAN潜变量预训练 | 20 epoch | 128 |
| Diffusion去噪预训练 | 20 epoch | 128 |
| 三类共享表示ES优化 | 各3 epoch | 8 |
| 三类完整模型优化 | 各3 epoch | 8 |

1 epoch遍历全部26,262小时。场阶段每轮3,283更新；潜变量阶段每轮206更新。三折诊断先用每月第2、4日训练、第15日验证的B内部面板，5 epoch；用于选择差异尺度及64/128维。全量表示训练后还需通过潜变量作用、整组留出、查询一致及标签隔离门槛。

AdamW，lr1e−4，weight decay1e−4，EMA0.999，梯度裁剪1，warmup500步；最后30%训练余弦下降至1e−6。GAN判别器AdamW的betas=(0,0.9)、weight decay0。FP32训练与采样；统计及区间重采样使用FP64。

单张A800串行作业，总额度24卡时。先做真实冷月数据准备、全部目标、35次采样反传、写盘和K16/K128评价短测；128维配置用于保守定价。硬件短测累计不超过1卡时；缓存准备与B训练内部诊断分别占用已登记的科学阶段预算，全部计入24卡时总额。包含全量训练、缓存、开发评价、全年候选复排的保守预算超限则停止，不自动缩减科学训练或扩大额度。

## 选模、指标与交付

第0步为基线，第200步只作启动检查；每完整epoch评价固定开发子集，保存raw与EMA的完整指标曲线。点产品按站宏RMSE、联合产品按固定站组ES，各保留三个正式候选。各阶段仍保存前三名候选及全部开发曲线。为控制重复评价成本，本轮在固定开发子集预先锁定10个正式产品：确定性对照的点产品1个，三类共享表示模型各一个联合概率产品，以及三类完整模型各一个点产品和一个联合概率产品。全年2019仅评分这10个产品，不再根据全年指标重新挑选checkpoint；表示训练中间产物保留开发结果。

全年使用K128 IID概率成员，其相同噪声前缀K64用于同一检查点的采样敏感性核查；点均值使用独立反向配对噪声池，概率ES-U不使用配对成员。报告RMSE、MAE、偏差、CRPS、观测NLL、ES、VS、80/90/95%覆盖与宽度；分组看季节、高程、站距、密度、边界及预登记天气过程。

结构评价报告0—25/25—50/50—100/100—200 km站间差值，原场相对4×4平均至100 km再回采样的收益，以及逐站打乱成员编号后的空间依赖变化。功率谱、场图及残差图用于解释；独立站与同步7日块bootstrap（2,000次）、14日敏感性提供精度证据。

交付每模型point_best/joint_best权重、训练和开发曲线、全年逐站集合预测、点值与概率地图、校准与宽度图、站间变化及空间依赖图、预登记过程场图和频谱、实际卡时和来源哈希。队列结束不自动读取D2020或扩展下一轮实验。
