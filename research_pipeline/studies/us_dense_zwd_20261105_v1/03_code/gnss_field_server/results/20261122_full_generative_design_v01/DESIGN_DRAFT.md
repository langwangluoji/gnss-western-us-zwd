# GNSS条件VAE、条件GAN与条件潜空间扩散：完整模型设计草案

状态：候选方案，正在进行网页Pro数学与实验设计复核；不是已部署模型。用户已授权定稿、介绍后实施和安排服务器训练。

## 1. 研究问题与统一输出

研究三种条件生成分布怎样在相同的观测信息和可学习场表示上恢复ZWD的条件均值、边缘概率及空间联合变化。所有模型发布144×96的统一高程ZWD场，25km为输出间距。真实监督为训练站的地表ZWD，通过统一格网查询与高程恢复计算损失。

已有融合背景场保持为已验证的输入与对照。名称使用“冻结站点重建网络”“A站反距离加权插值”“几何创新量校正”“融合背景场”，不再用历史实验代号向读者介绍模型。历史文件名、权重哈希保留在机器来源清单中。

没有独立密集真值。条件VAE用真实站似然学习近似后验与场解码器；GAN和扩散的潜空间预训练目标是冻结后验的抽样。该目标属于可学习的近似表示，不冒充真实高分辨率图像。最终预测仅读取输入站、粗条件、地形和时刻，不读取训练/开发/回顾站当前标签。

## 2. 数据与全量定义

- 训练：2016—2018全部合格名义小时及B角色真实监督，取消576小时上限。原始共有26304小时、13132476个B有效站时刻；资格还须经过四帧时间边界、固定几何和当前输入支持审计。
- 开发：2019年C角色，沿用锁定总体及查询算子。子集按月份×名义小时的时间排序1/3与2/3位置选取，最多576小时；完整2019用于候选重排。
- 回顾：2020年D角色继续封存。
- 旧B双折12小时结果是已暴露的增量诊断，新协议单种子完整训练不把它们当盲测。
- 新缓存保存原始A四帧、20通道100km条件场、融合背景和支持信息；从这些紧凑资料在GPU构建条件编码。避免预存约100GB的旧69通道全年重复展开结果。数据统计只用训练资料。

## 3. 候选公共条件编码器

粗条件是四帧×五变量、36×24格，插值到144×96。每帧另提供有效输入比例；加入高程及东西/南北坡度、归一化XY、陆地标记、融合背景、当前输入站距/密度、日与年周期量，共37通道。独立站点入口为174×31：四帧五变量20、四帧有效标记4、XYZ3、日/年周期4。

每个残差块为GroupNorm(8组)→SiLU→3×3卷积→GroupNorm→SiLU→3×3卷积，必要时1×1捷径；相加后除sqrt(2)。不使用依赖样本批量的BatchNorm。

| 层 | 操作 | 输出C×H×W |
|---|---|---|
| 网格入口 | 3×3 Conv37→32，残差块32→32 | 32×144×96 |
| 编码1 | stride2 Conv32→64，残差块64→64 | 64×72×48 |
| 编码2 | stride2 Conv64→96，残差块96→96 | 96×36×24 |
| 站点编码 | Linear31→64→64，SiLU | 174×64 |
| 几何注意力 | 网格Q、站点K/V，64维4头；距离/高差偏置，输入有效标记 | 96×36×24 |
| 编码3 | stride2 Conv96→128，残差块128→128 | 128×18×12 |
| 编码4 | stride2 Conv128→192，残差块192→192 | 192×9×6 |
| 全局条件 | 空间平均池化 | 192 |

37通道与31维站点特征必须以不可变字段表定义，不沿用旧缓存通道的隐式含义。全缺输入需有明确空token路径；输入支持域仅由输入有效性及固定几何决定。

## 4. 条件VAE

潜变量候选64维，表示同一时刻整张场的共同随机状态；不是逐站独立噪声。

- 训练后验：把32通道细网格特征查询到训练站，投影为64维，再拼接真实站标准化残差1、XYZ3、有效标记1，共69维；共享MLP69→128→128，掩码均值和最大值池化为256维；拼接全局条件192，MLP448→256→128，分成64维后验均值和对数标准差。
- 条件先验：全局条件192→256→128，分成64维先验均值/对数标准差。推理时只走这条条件先验，后验编码器不参与。
- 重参数化：z=mu_q+exp(logstd_q)*epsilon。
- 场解码：z64→256→1728，重排32×9×6；与192通道条件拼接为224，残差块224→192。随后逐级上采样并拼接对应条件跳接：320→128@18×12，224→96@36×24，160→64@72×48，96→32@144×96；1×1 Conv32→1得到统一高程残差，乘训练尺度后加融合背景。
- 输出卷积小幅非零初始化；潜变量到各解码尺度使用FiLM。训练记录潜变量敏感度，防止条件跳接使解码器忽略随机状态。
- 观测模型：发布场经双线性查询并乘exp(-H/3000)，再在观测端加入一次已锁定的误差项。观测误差与空间潜变量分开报告，不将站点独立噪声涂抹成空间细节。

VAE损失为每小时的“有效站似然负对数之和＋KL之和”，随后整体按该小时有效站数归一，最后小时宏平均。KL不能无意再除潜维数或任意乘极小系数。预热结束beta=1；预热与自由比特若采用，须同时保存原始KL及真实ELBO诊断。观测误差大小及KL预热细节待Pro与训练资料审计后锁定。

表示验收包括：活跃维数、后验/先验差异、固定条件换z后的场及站点变化、掩掉站组后的重建、打乱站序、发布格网查询等价、潜变量置零对照。训练内掩站诊断不称为独立留站验证；泛化主张依靠C2019及锁定后D2020。

## 5. 条件GAN

完整推理链是随机噪声→条件潜变量生成器→场解码器→融合背景相加→地表站点与完整格网。冻结公共表示后，GAN生成器和判别器从头训练。

- 生成器：独立标准高斯epsilon64与条件192拼接256→Linear256；四个LayerNorm/SiLU/Linear256残差块，条件与噪声通过FiLM注入；Linear256→64输出潜变量，不采用高斯场加零修正的恒等旁路。
- 潜变量判别器：潜变量64＋条件192，共256→256→256→128→1，LeakyReLU0.2、SpectralNorm，不使用BatchNorm。
- 观测判别器候选：逐站残差与条件/几何的掩码集合编码，再增加按距离分箱的站对差值编码，区分均值移动与空间相关变化。真实样本只来自真实训练站。其是否同时用于初训及最终微调待审查锁定。
- 预训练真实潜变量为冻结VAE后验样本；后续用真实站ES及对抗观测损失优化生成先验。单列纯潜变量预训练结果与真实站微调结果，不能将两者混为同一监督来源。

## 6. 条件潜空间扩散

完整推理链是独立噪声→多步去噪生成潜变量→同一场解码器→融合背景相加→地表站点与格网。

- 冻结后验样本仅用训练期统计进行逐维中心化和缩放。后验方差参与抽样，不只缓存后验均值。
- 去噪器：64维噪声潜变量→Linear64→256；sigma的32组sin/cos嵌入为64维，与192维条件拼接256→256→256；四个LayerNorm/SiLU/Linear256残差块并以时间/条件FiLM调制；Linear256→64。
- 标准EDM预条件，白化潜变量sigma_data=1；log(sigma)服从N(-1.2,1.2²)；带EDM权重的去噪MSE，先充分预训练。此时每个样本只需一次去噪网络调用，而不是从第1步就穿过35次完整格网U-Net。
- 推理固定18步Heun、35次潜变量网络调用，解码器在获得潜变量后每成员调用一次。真实站ES微调才穿过采样链；编码器、场解码器与白化统计保持冻结。
- 结果解释同时包括近似后验目标依赖与最终真实站评分，不把学习后验样本称为学习独立真实图像。

## 7. 训练、评价与工程候选流程

全量数据审计→紧凑月度缓存→真实工作集基准→锁定阶段/总预算→公共确定性场对照→条件VAE完整训练与表示验收→冻结编码器/解码器/潜变量统计→VAE/GAN/扩散先验充分训练→各自真实站ES微调→统一全年2019评价与出图→停止。三类模型共享数据、条件、发布查询算子和已验收表示。

训练按完整epoch而非72步定义；生成先验和微调使用不同学习率阶段。首个epoch预热，后续充分训练再衰减；以多个正式评价的点值和概率目标共同判断早停。精确epoch、更新数和预算待本机验收及真实A800基准锁定。

点产品和联合产品分开保存、报告选模步数，明确是否选择了零训练起点。概率成员必须独立同分布用于U统计ES。点均值可使用单独的反向配对噪声流降低蒙特卡洛误差；这一流不混入ES的无偏独立成员估计。

评价包含独立站宏/微RMSE、MAE、偏差、ES、VS、CRPS、80/90/95%覆盖率与宽度；逐站打乱成员、0—25/25—50/50—100/100—200km站间差值、100km平均回采样对照、稀疏/高程/边界/天气突变分组。功率谱与场图用于解释结构，不替代稀疏观测的精度证据。

单A800、同时最多一个GPU任务。分阶段独立作业、afterok及产物哈希/科学门槛，支持有界暂停和恢复；不使用一个临近超时的长作业装下整批任务。现有1卡时短筛已结束，新全量计划单独登记预算，禁止无限自动重投。

## 8. 原始方法来源

- Kingma & Welling，Auto-Encoding Variational Bayes：https://arxiv.org/abs/1312.6114 ，重参数化与变分学习框架；本项目观测算子适配为自行设计。
- Karras等，Elucidating the Design Space of Diffusion-Based Generative Models：https://arxiv.org/abs/2206.00364 ，EDM预条件、噪声采样与数值采样器。
- Rombach等，High-Resolution Image Synthesis with Latent Diffusion Models：https://arxiv.org/abs/2112.10752 ，先学习表示、再在潜空间训练生成分布的计算分解；原论文使用密集图像，本项目不借其结果宣称稀疏站已经识别全场。
- Ambient Diffusion：https://arxiv.org/abs/2305.19256 ，不完整观测学习的适用条件需核查；固定站网的观测零空间不会因网络更大而消失。
