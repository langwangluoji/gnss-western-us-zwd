# 误差上升诊断：2026-11-23

本次依据服务器last.pt中的完整训练历史、固定2019开发子集指标及部署版本对应的训练源码。没有提交新收费作业。

确认：B2016—2018训练逐小时站平均MSE每轮均值为57.6924、46.3980、40.9333、36.9022、34.0186 mm²；第六轮部分为31.8534 mm²。同期C2019开发站宏RMSE的EMA结果为9.4450、9.8289、10.0663、10.2356、10.3278 mm。初始模型9.3329 mm。训练MSE和开发站宏RMSE的聚合方式与样本不同，不能直接换算相互比较。

结论：优化器有效降低训练目标，同时跨站/跨年开发泛化退化。符合过拟合或训练与开发分布差异的表现。现有对照同时改变站点和年份，尚不能把原因独立归到空间或时间。没有证据据此判定GAN或Diffusion无效，它们尚未开始。

结构：冻结背景加可训练非线性残差；确定性阶段latent固定零，条件编码器与解码器共同训练。训练目标是B站逐小时MSE，没有对独立空间组进行内部验证的早停约束，也没有明确的残差幅值/平滑先验项。网络权重衰减仍存在，不能说完全没有正则化。

编排：epochs=min_epochs=10，patience=0；最后30%才学习率衰减，当前学习率1e-4。初始baseline单列，未进入正式candidate池；若所有训练候选差于baseline，不能把正式池最优称为底座改进，后续依赖应增加基线回退或明确停止门槛。

下一步证据：固定B时刻重评baseline/epoch1/current，分站距/高程/密度检查残差；用B内预登记空间组和时间块的小实验区分空间过拟合与跨年偏移；确认单位/查询/归一化的一致性。未完成这些诊断前不将降低学习率、增大网络或增加epoch称为已验证修复。
