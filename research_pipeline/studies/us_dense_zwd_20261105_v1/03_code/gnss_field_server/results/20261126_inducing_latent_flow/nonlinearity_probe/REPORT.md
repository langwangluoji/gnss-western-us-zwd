# 已训练潜流的非线性是否进入最终场

每种子选固定四个训练历史的首起点，不读GNSS目标值进行拟合。用1024个Gaussian噪声拟合latent线性代理，再用独立1024噪声检验残差能量。场中分母包括完整剩余GP方差，分子只计算非线性代理残差经实际解码后的能量；它是受所选条件和Monte Carlo影响的诊断，不是精确高阶累积量或预测收益。

| affine_frequency | 3.79089e-15 | 4.05204e-16 | 0.101772 |
| odd_time | 0.000951757 | 0.000174549 | 0.101772 |

完整32个条件点和权重来源见[summary.json](summary.json)。Affine近零残差用于核验诊断方法；odd可以保持中心对称而具有非线性。结果不用于选取新开发日期或改变本轮主指标。
