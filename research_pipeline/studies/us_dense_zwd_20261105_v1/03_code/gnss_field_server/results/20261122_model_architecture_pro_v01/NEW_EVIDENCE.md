# 本轮新增证据与待裁决事项

1. 候选双Gaussian载体的均值、方差、偏态、峰度及两点协方差，已由16点Gauss-Hermite积分逐项复核。b=0时逐成员复现原Gaussian扰动；最大数值差8.88e-16。数学成立不等于已证明GNSS精度收益。
2. 非线性变换与格网查询不交换。两个节点的例子，正确“生成格网再查询”的方差0.629512，先查询后套单点非线性公式得到0.65。未来发布方差必须由共同成员或四角联合协方差计算。
3. 若尺度系数看到了同一个Gaussian载体，零均值保证会失效：a=exp(0.3P)、R=aP的均值为0.313808。系数噪声与载体噪声独立是接口契约，而非建议。
4. B训练站×训练时刻的站点—季节残差诊断，先按A天气幅度和校准标准差归一化；每站季节分别计算中心偏态。约12%—22%的单元绝对偏态超过0.5。这是分层边缘诊断，不是已证实给定全部A条件的偏态，更没有完成时间块稳定性检验；它足以要求不默认真实分布完全对称。
5. τ=6.1827mm来自旧B残差协方差模型的拟合参数std[-1]，不是独立测定的仪器噪声。将其固定为Gaussian独立项，会把潜在场的偏态传到观测端时乘以[v_field/(v_field+τ²)]^(3/2)。按已校准尺度，448个合格B站的该因子中位数约0.155—0.157，最大约0.265—0.267。两系数载体单点场偏态上限为1，因此在固定尺度、固定系数下，很多站的观测偏态上限约0.16。这是结构选择的重要边界。
6. 上轮只缩场和缩整个观测集合的两个Gaussian校准有相近CRPS，但后者的VS更低：第0折1.21155对1.16894，第1折1.22949对1.19738。它提示需要分辨空间协方差与独立项的分配，尚不能直接确定τ应当缩小，也不是更一般协方差优势的终局证据。所有后续新参数拟合限于允许训练资料，并以空间内层验证。

当前不修改生产模型、不提交服务器训练。主备结构将在Pro审阅及上述边界核验后形成方案。

最终客户端校正：第5项的0.156是当前校准Gaussian查询方差下的稀释因子。非线性载体会改变四角协方差，双线性查询还涉及跨格点高阶矩，因此不能将格点偏态上限1直接乘此因子，称为新模型站端偏态的严格上限。新模型须重新计算查询后的矩；该数字仅用于说明独立项可能显著削弱可辨识的场偏态。最终结构及阶段划分见MODEL_PLAN.md。
