# 生成式场模型：本批结果后的验证安排

当前目标是确定生成模型在留出站上增加了什么能力，并据此选择下一轮训练。延续冻结M0＋IDW底座和相同条件，比较随机残差ResU-Net、Diffusion和GAN。当前六组训练已结束，每组684步；C2019、D2020未用于本批实验。B2018作为已有历史底座暴露的增量开发数据解释。

## 已完成的小实验

对正确指定的标准正态模型，每个K生成20万组独立集合，用正态CDF计算独立目标落入样本线性分位数区间的概率，再以不同种子、独立目标和均匀分布次序统计量复核。

| 成员K | 标称90%区间的预期实际覆盖 |
|---|---:|
|16|80.648%|
|32|85.035%|
|64|87.305%|
|128|88.641%|

这说明直接拿有限集合的线性插值分位数与连续分布标称水平比较，会把取样效应混入校准判断。此前“本批84%说明欠离散”的判断需要修正。这个正态参考不用于统一修正所有非正态模型的覆盖率，也不证明本批模型已校准；实际校准还需秩直方图和同K高斯对照。相关数据为finite_ensemble_interval_simulation.json，独立验核为finite_interval_independent_checks.json，图为finite_member_coverage.png/svg。

训练ES已使用非对角U估计，不因本项发现改训练目标。保留原登记CRPS数值，另补充Ferro形式的fair CRPS；适用条件为同一预测分布的独立成员。不同K的推断同时标注估计方式。

## 取回数据后立即运行的诊断

1. 复现两折高斯基线及各产品外层站宏RMSE、CRPS、站组ES/VS；逐项核对固定站时刻和原归档，误差阈值1e-6。两折分别报告联合指标。
2. 利用相同hour/member噪声配对：生成模型成员减去原高斯成员，恢复学习修正；其均值应与控制变量均值一致，容差0.001mm。
3. 构造“高斯集合＋生成模型均值修正”及“生成集合移回原基础均值”两个反事实。分别识别整体纠偏与分布/依赖变化。剩余收益可能来自协方差变化，不能直接归因于非高斯性。
4. 比较8/16/24/32成员前缀的控制变量均值和点误差，判断小幅模型差异是否稳定。K32无法代替K64/128实测。
5. 输出逐站随机化秩直方图、90%覆盖与宽度、同K高斯基线及成员打乱对照。校准与精度分别解释。
6. 场图和谱只用于已保存代表天气时刻的结构诊断；独立站间差值和25km对100km配对检验需要匹配全体评价时刻的格网。不能以一幅场图证明有效分辨率。

实现：tools/generation_postrun_diagnostics.py、tools/analyze_generation_postrun.py。核心分解、匹配掩码、非有限预测、随机化并列秩以及一维ES与fair CRPS等价性已有性质测试。待真实下载完成后运行全套真实结果分析。

## 研究方向判据

- 若外层收益主要由均值平移解释，优先解决跨站均值泛化；生成式分支保持点值与概率的独立职责。旧U-Net均值的两折外层退化记录仍然有效，内层降低不构成晋级。
- 若同均值条件下生成模型仍稳定改善ES/VS和CRPS，继续研究其分布/空间依赖；再比较Diffusion的额外采样成本是否带来足够收益。
- 若不同成员前缀改变模型排序，优先做更大K的固定检查点评价，训练步数暂不作为主变量。
- 若秩诊断在控制有限K后仍显示欠离散，再设计仅用允许开发资料拟合的校准实验。外层标签不用于选择放大倍数。
