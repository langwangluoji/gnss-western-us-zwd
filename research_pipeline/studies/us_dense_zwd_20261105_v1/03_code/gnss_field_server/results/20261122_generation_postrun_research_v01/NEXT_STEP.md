# 下一阶段：先解决空间选模与概率尺度，再比较生成结构

目标保持为：从稀疏GNSS条件生成可信的高分辨率场，并分别证明点值、细尺度和联合概率收益。6mm作为点精度的待检验目标保留。

## 1. 已确定的基础产物

- 沿用冻结M0＋IDW均值。新点值修正获得独立证据前，当前生成器学出的均值漂移不晋级。
- 登记训练资料拟合的场幅度Gaussian为强概率对照。两折α=0.598954/0.601355，仅缩空间场，τ独立保留一次。均值、先验、输入统计与评分清单均绑定哈希。
- 本轮outer96已参与发现，作为探索资料。C仍属开发，D2020保持封存。

## 2. 本机先做的最小实验

1. 在原拟合B内部按既有物理站组固定空间内层，与留天气块共同评价。依据几何及既定覆盖划分，不按误差挑组，不拆物理别名和密集组。该划分将减少实际训练站数，新的训练资格与时刻数重新登记，不能沿用684步为一遍的数字而不复核。
2. 对B训练资料做条件偏态诊断，先处理站点固定偏差、季节混合和天气幅度。条件偏态若稳定存在，采用保留偏态的独立先导方法作候选；反对称限制作为消融，不能默认符合真实分布。
3. 点产品独立训练均值修正，真实站MSE监督；用空间内层站宏RMSE与零修正比较。点均值更新后，仅用允许B资料重新拟合对应概率尺度。概率分支梯度不改变已选均值。
4. 概率产品从相同校准先验出发，先检验最便宜的均值保护随机分支。可测试δ_odd(c,u)=[δ(c,u)−δ(c,−u)]/2，其中先验及白噪声同时反号，A条件不变。每个独立u的两次前向只生成一个成员；ES-U不能把反向样本对当作iid成员。

其中c是固定的A站、历史粗场和地形条件，u包含先验随机场与白噪声，δ是网络学习的格网残差。

反对称方案固定条件均值，可表示对称非高斯尾部和空间依赖，同时放弃条件偏态；它不承担6mm点值目标。独立先导能保留偏态，但有有限先导误差和额外计算。上述机制先通过本机数学、格网查询与小范围学习验证后再选定训练实现。

## 3. 单张A800阶段的建议顺序

空间内层协议与本机验收通过后，再登记服务器短基准和预算：校准Gaussian → 均值保护随机分支 → 在其显示额外收益时登记独立Diffusion/GAN对照。继续使用小ResU-Net，先不加FNO、Transformer或额外复杂模块。

首个随机分支使用全部新协议合格训练时间，计划最多两遍；实际更新数由新训练站资格、有效批量和时间池确定，至少完成一遍后再按空间内层早停。若预算内持续改善，记录“尚未收敛”。

Diffusion和GAN采用相同信息、同均值、同校准先验和独立权重，按实际卡时及数据曝光比较。Diffusion均值保护可能增加计算图和显存，必须在同型号A800实测；不能直接把原63GB峰值乘二后提交，必要时比较梯度重计算或合法微批，保持有效批量及完整采样梯度。

这是新的资源申请，旧4卡时不是无限延续额度。本轮尚未提交任何新的收费作业；正式提交前锁定模型、更新上限、评价成本及总预算。

## 4. 评价与停止规则

- 点产品：空间内层站宏RMSE，另列MAE、偏差、覆盖人口；零修正始终可选。
- 概率产品：固定站组ES选模，CRPS/VS、解析或同K覆盖及宽度辅助；K64筛选、K128前缀复核，独立随机池检查。
- 细尺度：留出密集组的0–25、25–50km差值CRPS/覆盖/VS；公共高度Z0与低高差地表ZWD分别报告。均值场25km对100km回采样须用同一锁定站时刻清单。
- 按季节、高程、A站距离/密度、边界与地形梯度分组。天气突变事件优先依据A条件变化及训练期阈值预登记，不按外层误差选事件。
- 场图、功率谱密度（PSD）和梯度图检查异常纹理；它们不能独立证明真实细尺度精度。
- 若单参数Gaussian解释概率收益，保留校准结果；若空间内层仍选零修正，不扩大主干；若均值保护分支稳定优于强Gaussian，再推进Diffusion/GAN。

研究主线继续保留Diffusion/GAN。它们需要证明在强简单对照之上的额外价值，点值提升与概率改善分别验收。
