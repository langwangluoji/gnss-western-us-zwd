# 现有最佳结果与论文材料入口

截至2026-11-26，现有证据支持按任务选择模型：美国当前场用I1，美国六小时预报用有向时滞joint v2；概率场以匹配基础场的Gaussian、Affine和Local作配对比较。欧洲引入VMF3-FC后获得新的当前场精度。美国与欧洲的数据、信息条件和汇总方法分别说明，数值不合成统一排行榜。当前工作为结果整理，未启动新实验。

## 美国：当前重建与六小时预报

区域为25–50°N、125–110°W，2016–2019训练；2020每月8–10日为主日历、15–17日为补充日历，合计72个抽样日。410站训练池，137注册开发查询，当前与F6实际135站有标签，三个条件布局、两个训练种子。两组日期均已开发暴露。

| 任务与模型 | 主日历/mm | 补充日历/mm | 两日历合并/mm |
|---|---:|---:|---:|
| 当前重建，I1 | 9.817064 | 10.740343 | **10.319804** |
| 当前重建，joint v2 | 9.806169 | 10.767129 | 10.327014 |
| 六小时预报，joint v2 | 13.852222 | 16.077837 | **15.053927** |
| 六小时起点持久性，I1 | 14.959594 | 17.297820 | 16.219944 |

以上为站宏RMSE：每站按有效时刻计算RMSE，再平均站、布局及种子；合并日历先合并各站平方误差与计数。**9.806169mm是主抽样日历的当前场成绩，全年成绩尚未建立。** joint相对I1的合并当前差值为+0.007210mm，95%共同月份区间跨零，当前重建保留I1。joint相对同参数factorized的合并F6减少0.028948mm，区间[-0.042988,-0.015651]mm，支持其预报用途。

## 美国：已接入joint v2的概率场

最新融合冻结joint点场，重新拟合其残差上的条件位置、尺度、天气相关核与Affine/Local。下表是raw K32成员的双种子平均F6连续分级概率评分（CRPS，越小越好），来自相同条件和采样路径的配对比较。

| 概率模型 | 主日历F6 CRPS/mm | 补充日历F6 CRPS/mm |
|---|---:|---:|
| 天气相关Gaussian，G265 | 7.675242 | 8.771587 |
| Affine轨迹传输 | 7.672983 | 8.755594 |
| Local轨迹扩散 | **7.657557** | **8.750280** |

Local相对G265改善0.230%/0.243%；相对Affine的额外改善为0.201%/0.061%，补充日历区间跨零。Affine在内部时间增量和部分减湿事件评分上保有优势。这里的“配对比较”指共同实验条件，表中数值属于raw K32，须与严格保持joint总体均值的独立双场差分K16版本分开阅读。

确定性点输出仍为冻结joint，随机成员的平均值另行诊断。新概率分支的存在不改变上表点RMSE，也不能把概率评分改善写成确定性精度提高。旧TF3000残差模型与本轮joint残差模型分别保留来源。

## 欧洲：VMF3-FC物理背景与概率融合

2020–2023训练池为273站，2023开发留站用于选模；2024完整年度作历史已暴露回看。63注册确认站中59站有共同有效记录，共63494个站–UTC键。点预测先等权平均两个种子的预测，再在共同键上计算micro RMSE。

| 当前点场 | micro RMSE/mm |
|---|---:|
| 原p14＋GRU＋I1 | 15.927922 |
| 同结构新增校正器、VMF3输入置零 | 15.825800 |
| VMF3 aligned直接背景 | 12.666135 |
| 新VMF3融合基础场 | **11.406422** |

15.927922→11.406422mm的28.39%改善来自新增VMF3物理信息与均值融合。概率模型共享该新均值；Local的+6h CRPS为9.82785mm，相对同条件GP改善0.96%，相对Affine额外差值区间跨零。28.39%应归于点场条件与均值分支，扩散收益由概率对照单独解释。

欧洲每记录间隔6h，16记录历史跨度90h，七时效为0/6/12/18/24/30/36h；美国为逐小时七时效0–6h。欧洲还加入VMF3，且点指标为双种子预测集成micro RMSE，因此与美国站宏结果各自解释。
