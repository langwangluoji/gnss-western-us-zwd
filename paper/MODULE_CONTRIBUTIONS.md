# 模块作用、直接证据与归因

现有模型将当前空间重建、未来增量和条件随机场分开建模。模块贡献以同数据、同信息、同评价人口下的配对对照为依据；架构中存在某个模块，表示它承担相应功能，独立收益由相应消融确定。

## 术语与评价对象

| 术语 | 含义与本文用法 |
|---|---|
| ZWD | 天顶湿延迟（zenith wet delay），输出单位mm |
| 当前重建R | 使用起点及此前条件站信息，估计隐藏位置当前ZWD |
| F6 | 美国为起点后6h；欧洲+6h是第一个未来记录 |
| 创新 | 条件站观测减去同站同刻背景预测 |
| 站宏RMSE | 先计算每站RMSE，再平均站、布局和训练种子 |
| micro RMSE | 在共同有效记录上合并平方误差后开方 |
| CRPS | 连续分级概率评分，评价预测分布，越小越好 |
| Affine / Local | 同一Gaussian参考上的仿射轨迹传输 / 局部非线性轨迹扩散 |
| 配对对照 | 两模型共享数据、条件及相应随机路径；与独立双场差分变换分开使用 |

## 可用于现阶段文章的主张

1. **当前空间重建采用背景与历史创新。** I1的双日历合并站宏RMSE为10.319804mm，配对证据支持其相对原冻结背景的收益。
2. **未来预报保留逐站历史与有向时滞关系。** joint v2对同参数factorized的两日历F6收益复现，合并15.053927mm；贡献归于两项联合设计。
3. **概率场以天气相关Gaussian为基础控制。** 最新joint残差融合已实际完成，Local的边际、近邻、内部增量与事件评分分别报告；扩散独立收益由Affine对照限定。
4. **欧洲物理背景融合具有明确的点场价值。** 在2024年度共同键上micro RMSE为11.406422mm，新增VMF条件与均值校正承担该点场改善，概率分支另有匹配评分。

美国开发抽样、欧洲年度历史回看以及早期2018稀疏日历共同组成研究台账，各自保持原训练、数据角色、信息条件与统计口径。两种子的指标平均与两种子预测集成也分别标注。以上主张依据现有评价；strict_oof=false和已暴露评价条件保留在任务范围旁。
