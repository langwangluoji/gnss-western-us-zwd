# 地形路径屏障：开发回看审计

本目录只读既有seed42、2020每月8–10日、3布局、137开发站的缓存及冻结I1/Transformer预测；不训练模型，不读取确认/C/D标签，不下载外部数据。

预先固定审计：核对25km DEM实际中心坐标、米/千米换算及现有static映射；从每个origin当前GNSS mask恢复最近可见条件站；路径31点双线性DEM，报告相对站高连线的正屏障、超过两端最大站高的差，以及以DEM端点替换站高的敏感性。超出DEM中心支撑的路径明确标记，主分析排除。

控制分层：距离[0,50,100,150,200,300,+∞)km、月份、query高程[-∞,250,750,1500,2500,+∞)m。低屏障<100m与高屏障≥300m作共同支撑比较；每格每组至少2站、48条有效小时。共同支撑按两组较小样本量加权；报告样本/站数。按站和月份重采样给探索区间，保留重复origin的依赖。

现有地形信息比较：查询/条件站高差、两端roughness、坡度、站高减局地DEM、距离、海岸距离与月份/布局。固定5个空间块折的开发误差诊断比较新增屏障前后R²；该值衡量误差相关性，不是新ZWD预测精度，也不是训练或空间确认结果。

产物由`audit.py`生成：`audit.json`、`REPORT.md`、`terrain_path_audit.png`、轻量`pair_features.csv`及`controlled_cells.csv`。报告应保留近海高误差站的反例，并区分相关性与因果解释。
