## 冻结设计

继承欧洲v2的411站元数据、273训练/64开发/63确认/11新站分组、2020–2023训练池、2023留站开发选择及2024年度回看。保留现有模型、权重、科学锁和15.927922mm主结果。

原CNN的三个VMF3特征为站点native ZWD、VMF3总延迟减Saastamoinen ZHD的aligned值、aligned减原背景的anomaly。本轮沿用其VMF3-FC1°四邻点逐点垂直修正后双线性算法。缓存7307/7308历元可用，缺2023-12-18 00UTC；新模型用缺测mask，不用未来有效时刻填充。

本模型保持已有参考站GNSS/T/P条件：aligned中的站压由条件站T/P按干空气高程传递并空间加权估计，缺测回退到VMF3自身静力项；不读取目标站T/P、WVP、TCWV或FFT-SCHA。anomaly减本模型I1场。原CNN保留自身站压与FFT-SCHA定义，因此三特征算法同源、对齐参考各自遵循原模型。

## 架构和对照

冻结p14＋GRU＋I1 → 111维已有时空查询条件；另一路逐查询点16步VMF3三特征＋mask → GRU32；当前三个VMF3特征及GRU状态与已有条件拼接 → 64/32层MLP → 零初始化校正头 → 最终ZWD。新增分支初始严格复现原场。

并行定义两臂，均seed42/17、各3000连续四记录块、相同条件站/目标站布局：

- control：同结构，将全部VMF3输入置零，检验新增校正器本身收益。
- vmf3：输入当前与历史VMF3三特征及有效mask，检验VMF3额外收益。

原CNN-LSTM-XGBoost保留上轮固定预测，不再训练；澄清前完成的seed42试验及停止的seed17试验本地归档。VMF3 native和aligned自身作为直接背景基线。主评价对齐上轮确认站63494共同键。所有基础场选择只用2023开发站；2024新结果用于历史暴露年度回看。

当前是冻结强基础场后的背景特征融合试验，尚非全骨干联合再训练；不把概率/扩散收益混入点RMSE。
