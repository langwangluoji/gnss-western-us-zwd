# 架构与图件核验

日期：2026-11-25。范围为设计与图件，本轮未修改网络实现或启动新训练。

独立实现视角审阅核对了p14的proj/down两级16/32通道，以及逐锚点72小时窗口。补充后的重要合同如下：

1. 残差事件以fold、条件布局和连续块为键，不拼接不同基础场来源的站点残差。
2. 各空间折的隐藏通道不直接用于概率条件；跨折共享G使用原始允许信息与同单位基础场输出。
3. 生成端使用标准化创新逐帧epsilon扩散及固定有界AR潜递推。可逆标签变换构成有效受限联合族；时间依赖由AR承担，扩散学习帧内创新分布。
4. 真实过去潜状态仅用于构造训练创新标签，采样条件不读取它。块首start显式输入、状态归零，各成员保留自己的生成状态。
5. 基础场、物理残差、潜状态和创新使用明确且独立登记的归一化；完整逆变换和Jacobian均已写明。

三张图均导出PNG和SVG。PNG已逐张目视检查，文字、节点与箭头完整；脚本检查文字边界。新网络因果性、重构精度和实测性能属于后续实现验收，图件核验不替代这些实验。
