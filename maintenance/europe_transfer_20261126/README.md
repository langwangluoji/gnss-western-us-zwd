# 欧洲 Model4 数据上的架构迁移

用户授权：2026-11-26，将美国最佳架构迁移到欧洲；采用相同训练区域、站点和年份，与原 CNN-LSTM-XGBoost 比较最终 RMSE。两模型各自保留特征，不混用。原项目只读，所有新产物放在本目录。

## 固定数据合同

- 来源：Model4 当前修复版 `euref_train_2020_2023.h5` / `euref_test_2024.h5`；2024 为历史已暴露的回看年度。
- 按1km连通物理站址分组，400个训练期站由坐标空间分层、固定随机种子划分为273训练、64开发、63最终留站；2024新站11个单独报告。初版280/60/60按站号提案已归档为 `*_proposal_v1`，发现75个近同址站号后改用v2组划分；分组不使用ZWD数值。两方法使用同一273站训练池，最终比较共同站–UTC有效键。
- 正式v2使用完整2020–2023训练站池，2023监控保留开发站址隔离，因此是空间开发监控；2024作年度回看。先行v1按旧CNN阶段用2020–2022神经拟合，单独保留。原系统保持自己的阶段安排：背景2020–2023、CNN2020–2022/2023早停、XGB2023。两系统总体训练站和训练时间池一致。2024不参与拟合、调参或模型选择。
- 连续6h UTC网格，缺测保留NaN及mask/age，不插值生成观测。16记录历史跨度90h（通常称4天窗口），7输出分别0/6/12/18/24/30/36h；主比较当前ZWD，另保存+6h。
- 新模型只读 ZWD、温度、原始ERA5气压、站位高度、ERA5地形；P由干空气静力公式重新修正。现成ZWD标签沿用Model4定义；旧制包按湿度变量完整性筛选的影响随数据继承。
- 海岸采用Natural Earth 1:50m海岸线；欧洲投影EPSG3035。首轮地形为站点ERA5地形插值的粗地形，而非美国SRTM细地形；梯度/粗糙度由此场派生并注明尺度。

## 架构与对照

1. 迁移实际p14 `FixedSupportModel`：113维多尺度点特征、30通道固定载体U-Net16、自由坐标查询；接回原GRU历史空间分支和海岸/地形边分支。从欧洲数据重新训练，不套美国归一化或权重。
2. 在训练站构造模型创新，拟合9维I1历史岭头；查询站标签及历史不进入条件。原生逐站Transformer编码15维ZWD/T/P、mask/age、创新、时钟，保留站点身份；通过地形/海岸条件查询和有向站×lag传递校正场。新增读出保持零初始化。
3. 原模型复用原项目FFT-SCHA、CNN-BiLSTM-Attention及XGBoost实现，按相同273训练站筛选后重新拟合；保留原版湿度和自身历史特征。两套结果是系统比较，不能将差异全部归因于神经结构。
4. 美国最优点输出来自确定性基础场；本次首先迁移并验证该输出。概率/扩散不参与最终点RMSE选择，不把旧概率权重直接拼接到欧洲残差。
