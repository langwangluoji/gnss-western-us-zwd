# 项目方案复审：回到Diffusion与GAN的完整对照

2026-11-21。依据实际部署入口、冻结checkpoint、全年开发评价、本机三臂结果及原始论文进行针对性方法审查。新生成模型尚未实现或提交；本文更新研究优先级，不改写历史配置和结果。

## 1. 结论与需要纠正的判断

下一轮应固定已有基础场和空间表示，在全部允许训练时刻上完成条件EDM、条件GAN与可学习联合高斯的对照。小规模试验用于检查程序、估算资源和发现明显失败；小样本均值头的3%收益不再作为开展生成研究的必要条件。

此前研究安排偏向持续修正mean和局部特征，使生成方法比较迟迟没有完整落地。复杂度主要积累在实验分支、缓存、阶段依赖与评价解释上；实际训练的EDM只有41280个可训练参数，尚不能把结果归因为网络过大。

“全量”需要分清两个问题：覆盖所有允许时刻，以及在这些时刻上充分优化。M0 checkpoint的训练游标覆盖17526小时，5000步×8小时约相当于2.28遍抽样；服务器mean使用6288个B2018合格小时，两遍覆盖试验为1572步。后来局部模型只取384小时，1000步相当于20.83遍抽样，其问题可能是天气多样性而非单纯缺更新数。完整数据不包括开发/回顾标签，也不取消合理的时间缓冲。

## 3. 当前瓶颈

### 监督目标与空间可辨识性

现有资料是稀疏站观测，A-IDW粗场由同一批输入站计算，并非独立数值天气背景。任务是由稀疏观测条件生成空间场，现阶段不具备普通图像超分常见的独立成对高分辨率真值。IDW或克里金参考图可用于条件与分析，但把它当真值训练，会把插值规则变成学习目标。

格网增密、场图更锐利和功率谱更丰富均不能单独证明新增细节正确。短距离独立站差值、100km降采样对照与观测覆盖范围共同限定场的可验证能力。

### 实际EDM实验与通常理解的EDM训练不同

实际跑出结果的入口`training/observable.py`与`tools/local_subspace_pilot.py`，调用的是`SubspaceEDM`。它从近似高斯分布初始化，使用18步Heun（35次网络调用），通过完整采样链反传观测端ES；这条入口没有先做常规去噪score-matching预训练。

这一方法可以是有效的概率模型训练，ES训练有理论与实证依据，但它不等同于“标准残差扩散已充分训练”。工程中另一条`training/pipeline.py`包含去噪及GAN阶段，尚不能将其定义或测试通过当作与现有R64版本兼容的真实训练结果。

### 生成模型有一大部分输出随机性被冻结

按当前先验协方差而非真实大气分解，C可评分站中可由R64子空间改变的方差平均占总建模方差49.44%，固定站端τ项占46.29%，其余为固定高斯余项。B对应约48.92%与49.24%。这些是逐站比例的平均值，不能解释为真实误差中有一半不可改进，也不能把τ直接当仪器噪声下限。

此设计有助于短试稳定性，也限制了生成模型改变校准和非高斯结构的范围。需要以B交叉拟合残差审计τ、条件尺度及余项，统一用于全部模型；C/D不能用于人工补噪声或调覆盖率。

### 评价与晋级规则的适用范围

局部模型的288小时是12段24小时，7/14日重采样得到同一分区，不能当作两种连续周尺度稳健性证据。将两折均值按站拼接后的联合ES也不代表一套可部署整场模型。

3%均值改善门槛可以筛选一个以点值纠偏为目标的分支，不适合作为Diffusion/GAN研究的统一准入条件。概率收益需要ES、VS、CRPS、区间覆盖和宽度评价；点值和概率两条结论分别判断。

## 4. 简化后的共同架构

```text
同一A站四帧条件、A-IDW粗场、地形
                    │
          已验收共同条件与冻结mean
                    │
          同一R64空间残差表示
             ┌──────┼──────┐
             │      │      │
          联合高斯   EDM    条件GAN
             │      │      │
             └──────┼──────┘
          同一解码、拼接、站高恢复
                    │
       独立站点值／空间依赖／校准／成本
```

本轮冻结M0及已有优选mean，不再以其调参为主任务。空间基与R64先保持固定，避免在比较生成方法时同时改变表示。旧PCA32作为首轮共同条件；它是否损失预测信息属于后续同条件编码消融，不能从输入方差保留率直接下结论。

首轮系数域采用小型残差MLP：宽度128、4个残差块、R64输出；EDM额外输入噪声级编码，GAN输入随机系数并配独立条件判别器。现成标准系数EDM(width128)约250304参数、GAN生成器154048、判别器45569，可作为实现起点；参数规模同量级但不完全相等，需单列每次调用、判别器更新及实际卡时。

联合高斯应允许学习系数均值和稳定的协方差，作为强概率基线；不只比较冻结旧高斯。为防止把相关性改善误称为非高斯收益，优先使用R64全协方差高斯作为主对照，并同时保留旧高斯作可追溯参考。

系数索引没有二维邻近含义，不将64系数任意排成8×8套U-Net。若后续具备可靠密集格网目标，或验证通过适用的部分观测生成学习方法，再将EDM与GAN共同换成32/64/128通道的小U-Net；不默认加入Transformer或多种额外模块。

## 5. Diffusion与GAN怎样公平比较

1. 两者使用同一条件、基础场、解码器、B训练小时及系数目标来源。
2. EDM做标准去噪预训练；GAN做实际对抗训练，保留判别器日志、模式覆盖与稳定性记录。
3. 从B真实站残差逆算的系数只作为代理初始化目标，须检查可恢复性和收缩偏差。岭后验均值及其抽样都不等于独立高分辨率真值，不以代理重建分数证明真实超分。
4. 保存原生预训练阶段产物，另保存两者真实站ES微调产物。若GAN微调关闭判别器，命名为“GAN初始化＋ES微调”，而非声称最终仍由对抗目标训练。
5. 比较总产品收益，并用独立噪声池估计均值位移，另作共同均值下的形状对照。控制有限集合均值噪声，不能让32/64成员平均的采样误差决定RMSE排名。
6. 等数据遍历量与实际卡时两种成本同时报告，不以相同步数或相同参数量冒充相同计算量。EDM一次微调更新包含K4×35次网络调用；GAN还含判别器计算。

首轮不自动开启Optuna、不追加秩搜索，不以GAN是否胜过EDM决定是否运行。已有局部头结果作为已完成消融，不作为生成主线必经门槛。

## 6. 完整训练安排

阶段允许年份保持2018年B训练，2019年C开发，2020年D锁定后回顾。训练资格与留出周采用显式清单；当前覆盖包的6288小时是可用参照，重新核验系数逆算所需站数和选模资料后锁定各阶段实际小时。不能为了叫“全量”把留出小时塞回训练。

按小时有效batch32，6288小时约197更新/遍。建议首轮预训练上限50遍（约9850更新）、观测ES微调上限20遍（约3940更新）；这些是可审阅预算建议，不是“达到这些步数必然收敛”。正式运行前按阶段实际小时重算，观测微调若有效batch8则20遍约15720更新，不能沿用3940。

至少记录完整数据遍历数、独特天气小时覆盖、累计监督站时刻、梯度尺度、训练与开发损失、raw/EMA及样本多样性。开发评价每2遍与阶段末进行，合理最短训练后连续5次无预登记主指标改善则早停；点产品与联合概率产品分别保存，不从不同checkpoint拼接最好指标。

完整周B开发2016小时与全年C分工明确：B诊断不能反复决定超参后再称盲验证；C仍是已暴露开发年。D继续封存。每折单模型整场指标独立计算，不将跨模型拼接ES当产品。

作业采用单张A800串行队列：共同输入/目标审计→真实型号短基准→高斯→EDM→GAN→锁定后的全年开发评价与报告。100–200步短基准用于验证实际ES反传、显存、加载/缓存、采样和恢复，然后锁卡时与墙钟上限。旧小MLP的分钟级记录及原“约4卡时”不能代替新结构实测。

## 7. 验证重点与研究判断

- 点值：站宏/微RMSE、MAE、偏差；相同人口、输出间距和站高恢复。
- 空间细节：0–25/25–50/50–100km站间差值、原场与100km降采样版本、站对与组数。
- 概率：ES、VS、CRPS、80/90/95%覆盖和宽度；逐站打乱成员对照检验联合依赖价值。
- 情景：稀疏/缺站、地形起伏、高程、边界与天气突变；报告有效样本数和支持覆盖。
- 图像：均值/样本/标准差/修正场、独立站误差地图、可靠性图、变差函数、共同掩码下功率谱。谱是结构诊断；对插值参考图的PSNR/SSIM仅是参考一致性。
- 成本：完整流程卡时、峰值显存、每小时K64场的延迟与存储量，GAN判别器成本单列。

达到工程与数据验收即可进入完整生成对照，不再要求mean先改善3%。完整训练后允许出现“点值相近而联合概率改善”“GAN更快但校准不同”等有边界的结果；若都无收益，再根据形状、代理目标和条件信息诊断决定是否改表示或引入独立天气背景。

## 8. 最强反对意见与回应

**反对：既然有著名U-Net，为什么还用系数MLP？** 系数域比较能复用真实站监督和已验证解码，成本低、归因清楚；它的结论范围是同一空间表示下的生成方法，不代表一般图像扩散。格网U-Net需要匹配监督来源和观测学习方法，名称本身不提供这些信息。

**反对：全量训练就会自动恢复细节。** 更多合格天气小时能减少抽样偏差，充分优化能检验模型能力，但固定稀疏几何的不可辨识区域仍需先验与独立证据。

**反对：没有去噪预训练，旧EDM结果就没价值。** 旧实验有价值：它检验了ES训练的扩散参数化，并完成均值归因和恢复验证。它尚不能用于排除标准去噪预训练、更多训练覆盖或其他表示的收益。

**反对：只要PSD接近就证明超分。** 在相同插值先验上生成错误纹理也可能匹配谱。独立站和空间依赖评价需要同步支持，且不能从有限站点外推全陆地面积平均误差。

## 9. 文献与本地证据

这是针对本项目机制的文献核查，非系统综述；未声称穷尽2026年文献。

- Karras等，2022，EDM：[原论文](https://arxiv.org/abs/2206.00364)、[官方代码](https://github.com/NVlabs/edm)。支持区分网络、预条件、训练目标与采样器，并明确35次调用的计算性质。
- Mardani等，CorrDiff：[原论文](https://arxiv.org/html/2309.15214v4)、[期刊版](https://doi.org/10.1038/s43247-025-02042-5)。其低/高分辨率训练资料来自ERA5和区域WRF，不能把该监督基础等同于本项目的A站IDW与稀疏B观测。
- Ravuri等，2021，DGMR：[原论文](https://arxiv.org/abs/2104.00954)。使用雷达场监督研究概率生成的空间结构，说明GAN与Diffusion比较应保留完整概率与结构指标；不构成GNSS场精度保证。
- Pacchiardi等，2024：[JMLR论文](https://jmlr.org/papers/v25/23-0038.html)。支持直接以proper scoring rules训练生成网络，但不把这种训练自动称为标准对抗或去噪目标。
- Daras等，2023，Ambient Diffusion：[论文](https://proceedings.neurips.cc/paper_files/paper/2023/hash/012af729c5d14d279581fc8a5db975a1-Abstract-Conference.html)。从不完整观测学习的可行性依赖观测/腐蚀条件；固定GNSS几何不能直接套用其可辨识性结论。
- Scheuerer与Hamill，2015：[Variogram score论文](https://doi.org/10.1175/MWR-D-14-00269.1)。支持以对相关结构更有辨别力的评分补充ES。

本地核心证据：`architecture_scope_audit.json`、`results/20261120_postcoverage_analysis_v01/RESULTS.md`、`results/20261120_mean_convergence_v01/RESULTS.md`、`results/20261120_local_context_three_arm_v01/RESULTS.md`及各自绑定源码/checkpoint。上一轮配对LR/完整周计划保留为备用诊断，其小样本均值门槛不再阻断生成主线。本次未修改或启动训练。
