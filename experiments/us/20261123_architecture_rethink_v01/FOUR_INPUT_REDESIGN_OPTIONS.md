# 四类输入下的完整生成模型：架构与资料组织备选

日期：2026-11-23。研究方案，尚未选定实施版本；本轮不提交收费作业。以部署需求为起点，先确定架构，再用受控优化对照验证。本文与旧实验并列保留。

## 1. 成品任务

输入独立粗气象、可见GNSS站的IDW、原始GNSS集合和精细地形，生成144×96、25 km输出间距的ZWD集合。部署端仅使用上述条件及历史，不读取监督站或高分辨率参考场。

GAN、Diffusion和VAE分别训练自己的完整条件模型。共享资料契约、网络结构家族和发布查询规则；不要求共享权重，更不把VAE解码器设为其他两类模型的依赖。

## 2. 三条可比较的路线

|路线|核心组织|优势|需要解决的条件|
|---|---|---|---|
|直接条件格网生成|天气、站网、地形编码成多尺度条件；各模型独立生成整张场|部署直接、成员空间身份明确、适合统一格网评价|完整全场Diffusion预训练需有来源明确的稠密训练目标；站点监督不能自动提供全图真值|
|条件集合与位置读出|天气格网编码＋稀疏集合编码，学习位置条件分布|直接利用真实站标签，适合不同站网几何|须区分边缘输出和联合成员；正式排名仍先生成发布格再查询|
|气象条件先验＋GNSS推断|先学习给定气象和地形的场先验，再用A观测更新|可分别检验物理空间先验和观测约束|推断成本和采样校准需检验；先验条件不能已含同一A-IDW后又当独立证据乘A似然|

推荐优先细化第一条的紧凑多尺度结构，并用第二条提供只具站点监督时的明确对照。第三条保留作独立研究分支。三条路线的选择取决于训练资料可用性，尚不是三项均须执行的任务。

## 3. 资料按来源组织

|资料对象|保存内容|可读取者|
|---|---|---|
|独立气象|原产品、版本、变量、原生格距、垂直坐标、有效/发布时刻、同化说明和掩码|四路条件构建器|
|可见GNSS|A物理站ID、坐标、高程基准、四帧ZWD与质量标记|四路条件构建器|
|A站派生表达|IDW、相对气象背景的创新量、密度、最近距离、支持标记|条件构建器；与A同源，不作为独立观测似然|
|精细地形|DEM、与气象格点地形之差、坡度、地形统计、陆地掩码|条件构建器|
|训练标签|B站观测及有效标记|训练目标模块；不由推理条件路径读取|
|开发/回顾标签|C2019、D2020|分别由开发与锁定评价模块读取|
|训练期稠密参考（待确定）|模式/分析剖面、ZWD计算依据、原生尺度、空间时间覆盖、同化暴露说明|稠密预训练目标模块；不是成品运行依赖|

四帧沿用0/6/12/18小时；各来源单独标记缺测。原有五变量共同有效规则保留为可复现旧对照，新入口应将气象缺测和GNSS缺测分开，让某项站点辅助量缺失不会无说明地抹去有效ZWD。

气象剖面能构造ZWD时，依据温度、水汽压与垂直坐标积分，并处理地形截断。只有PWV时必须说明转换及其温度条件。产品并非GNSS插值，不代表它没有同化GNSS；独立来源与独立验证是两项不同的审计。

回顾研究可使用再分析；实时成品应另行锁定可获取的NWP发布时间和延迟。当前名义小时对齐不等于实时可获得性。

## 4. 推荐条件结构的起始形式

1. 天气分支先在原粗尺度编码四帧，再形成多尺度天气特征，保留物理量与各自掩码。
2. 原始站点用共享小MLP编码ZWD、相对背景创新量、相对位置、高差与质量，经归一化局地核聚合到格网，保留密度与无站标记。
3. IDW分支用浅卷积编码其数值和支持，随后与原始站集合特征融合为同一个观测分支。两者作为互补表达，不增加统计上独立的观测份数。
4. 地形分支用浅卷积编码高度、坡度、相对模式地形等条件；精细DEM提供的信息在25 km格内也可用地形统计表达。
5. 多尺度条件融合后接紧凑ResU-Net。本轮Pro建议的轻量候选宽度为32/64/96/128/192，对应144×96、72×48、36×24、18×12、9×6；每尺度一个包含两层3×3卷积的残差块，GroupNorm与SiLU。镜像解码回128/96/64/32，双线性上采样并拼接skip，最后1×1卷积输出一个残差通道。该候选替代上一份32/64/128/256、每尺度两块的起始提案；尚未经本轮显存与收敛验证。

可先测试的分支通道为：气象56→16→16（七个值及七个mask、四帧）；IDW20→8→8（各帧创新、有效性、最近站距离、邻站数、年龄）；原始站共享MLP6→16→16，逐帧归一化聚合的16特征加密度共68通道，再68→16→16；地形8→8→8。IDW8与站点16经1×1融合为16，再与气象16和地形8合为40→32。天气先在原粗尺度编码，再对齐到相应融合层。七个气象候选为剖面积分ZWD、Tm、2m温度、地面气压、TCWV、10m两方向风；数据审计后才固定实际通道。

创新量在每帧由同帧A观测减去气象背景在该站位置与高度的预测得到，全程不读取B/C/D当前目标。无站时保留天气与地形路径。随机缺站需同步重建被影响的IDW、创新量和历史条件。

气象与站网条件特征每小时编码一次。Diffusion的各次去噪复用条件特征，避免重复读取数据和做站点聚合。联合训练时只能缓存原始派生条件，不能缓存正在更新的编码器输出。

## 5. 高程处理的两个契约

旧对照继续采用公共高度格网加固定exp(-H/3000)查询，保证历史成绩可复现。新方案可以比较气象剖面积分背景与残差高度转移，但这属于查询/表征协议的显式变化，不能把新旧成绩直接混用。

如使用新高度算子，所有新模型和简单对照须重新通过同一格网发布与查询，单独登记版本。气象背景的站高计算准确，并不自动证明其剩余误差在所有高程相同；残差高度规律也须内部留组验证。

## 6. 三类模型的训练契约

|模型|完整路径|仅站点资料可成立的目标|稠密参考能支持的目标|
|---|---|---|---|
|条件VAE|条件先验＋训练后验＋自身空间解码器；推理只采条件先验|B观测似然与KL；先验样本的站组适当评分|稠密重建/似然与KL，学习参考资料的空间分布|
|条件GAN|空间随机输入＋自身条件生成器＋自身判别器|带坐标、掩码和相同条件的真实B集合与生成查询集合判别；站组评分|真实参考图与生成图的条件判别；不把插值图当真实图|
|条件Diffusion|全场加噪状态＋自身条件去噪器＋固定采样器|观测值集合去噪可作为独立路线；不等同于完整全场监督|来源明确的干净残差场去噪，随后在真实A/B条件下适配|

稀疏似然和观测域判别能形成可计算训练目标，仍需先验决定未观测区域；不能据此宣称全域结构已获真实监督。若有物理预训练，真实站适配可比较保留参考回放与完全适配；这是单独消融。

本轮Pro的空间随机状态候选为4×36×24，投影到96通道后注入100 km层，再通过深层与解码路径影响全场。VAE先验96→8产生均值/对数方差，训练后验额外读取B创新集合；GAN使用标准高斯潜场及自身生成器。3456维潜状态相对稀疏监督偏大，首轮需通过先验样本、KL及潜变量扰动诊断决定规模，当前不锁定。Diffusion直接从1×144×96全域高斯残差场采样，不借助上述潜场解码器；32通道条件加带噪残差后33→32，噪声嵌入32→128→128注入各块。

若有稠密参考，公平主比较给三个模型相同资料。若尚无稠密参考，VAE与观测域GAN可先做站点机制验证；完整格网标准DSM待目标来源确定。只用站点ES端到端训练扩散采样器是另一种可研究目标，须单列登记，不能当作标准全场去噪预训练已经成立。

生成成员可具有非零条件残差均值。最终点预测使用部署采样的集合均值，不能用内部背景或训练后验重建替代。点MSE若施加于每个独立随机成员，会压缩随机性；点值与概率目标需分别说明。

## 7. 本机验证与服务器移交条件

- 在已知合成场上分别控制天气偏差、地形相关、锋面和缺站；比较相同条件的简单估计与完整生成模型。高斯合成案例用可计算的条件分布区分不可消除不确定性与模型误差。
- 在真实B内部按物理站组与天气时间块分别留出；旧学习背景已见过的留组标签必须标作暴露，严格验证须排除整条学习链的标签接触。
- 最小输入消融为：天气＋地形、再加IDW、再加原始站集合。每次改变一个输入条件，保持训练预算和查询协议一致。
- 优化实验从同一checkpoint、优化器及样本游标分叉，比较原调度与预算内充分衰减；在固定样本重评raw/EMA、MSE和站宏RMSE。当前验证恶化不能直接归因于生成模型或确定为过拟合。
- 按点值、0—50 km等站间差值、ES/VS/CRPS、覆盖率和区间宽度评价；频谱和场图说明空间结构，不替代独立站证据。

正式服务器预算按新架构的实测更新、采样与评价开销重新锁定。单张A800串行；不沿用旧三模型训练时间预测，不以预设步数保证收敛。首版优先减少重复数据构建，而不是先扩宽网络。

## 8. 当前建议顺序

先审计少量独立气象剖面与原生格网，确定来源、时间和高程契约；在本机以含山地及站网空洞的小范围，验证四分支确定性对照与完整条件VAE的先验预测。VAE先行依据训练目标明确与采样成本，研究优先级仍保留GAN、Diffusion和VAE三者比较。

随后在相同参考信息和真实站适配条件下比较完整GAN、Diffusion与VAE，分别检查噪声利用、后验与先验预测差，以及自由扩散采样校准。输入/结构改动和学习率调度分别消融。待本机机制证据与新单卡基准形成后，再锁定全量服务器预算。
