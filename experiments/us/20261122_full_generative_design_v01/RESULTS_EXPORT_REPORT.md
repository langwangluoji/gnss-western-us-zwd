# 训练与独立站评价图表导出

`src/gnss_field/generative/report.py` 提供 `export_campaign_figures(campaign) -> dict`，由全年最终评价完成后调用。函数依据 `manifest.stages.final_evaluation.reports` 中实际选出的 point/joint SHA256，读取完整条件 VAE、条件 GAN、条件 Diffusion 与确定性场对照。它返回真实生成的文件路径、所用档案及明确的跳过原因。

## 生成内容

- 训练目标曲线：各训练阶段分别绘图；同时导出所有数值训练历史 CSV。
- 开发集曲线：逐阶段绘制 raw/EMA 的站宏 RMSE 与站组 ES，保留基线、启动及正式评价标识。
- 独立 C 站地图：每个模型 point 产品的逐站 RMSE，以及融合背景 RMSE 减模型 RMSE 的增益。地图使用投影坐标和真实站位置。
- 80/90/95% 观测预测区间：覆盖率、区间宽度及覆盖率—宽度图。计算先在各站内按有效时刻平均，再对有观测的站等权平均，与现有集合评价口径一致。
- 站间差值：0–25、25–50、50–100、100–200 km 四箱；另列高度差不超过 100 m 的站对。CSV 同时记录几何站对数、实际存在同步有效观测的站对数及有效站对时刻数，导出 RMSE、MAE、偏差及相对背景的差值 RMSE 增益。最后一箱包含 200 km 端点，其余为左闭右开。
- 配对 bootstrap：point 产品相对融合背景的站宏和微平均 RMSE 增益；2000 次同步 7 日循环时间块，并给出 14 日敏感性。第二方案在相同时间块上叠加固定 50 km 投影格组重采样，保留单站格，作为空间组敏感性。JSON 记录格组定义、固定种子、实际块长、有效重复次数与 CPU 用时。置信区间采用配对增益分布的 2.5%/97.5% 分位数。

默认输出目录为 `campaign.root/evaluation/figures/`。完整合成样例生成 8 张 PNG、6 个 CSV、bootstrap JSON 与图表清单 JSON。CSV 分别保存 point/joint 产品，校准图使用 joint 产品，精度和站差图使用 point 产品。point/joint 选中同一 SHA256 时共读一次；选中不同档案时分别计算。

## 资源与证据边界

导出使用 NumPy 与 Matplotlib Agg，逐档处理样本集合，按 168 小时分块计算分位数；不同时加载多个候选集合。bootstrap 先累计站点误差平方和及有效计数，再按块汇总，避免每个重复重新扫描全年站时刻。最终清单单独记录 CPU 导出时间。

图中数值来自独立 C 站观测。25 km 输出间距与站点精度分别解释，图表不提供独立密集格网真值结论。高度数组缺失时明确跳过高度条件面板。此模块计算点值 RMSE 增益区间；ES 置信区间及天气过程/频谱由其他评价模块负责。

## 验证

先建立合成归档测试，确认缺失 report 模块时出现 3 项预期失败；bootstrap 增补测试在缺失输出键时再次确认预期失败。随后运行：

```powershell
$env:PYTHONPATH='src;tools'
$env:OMP_NUM_THREADS='2'
& D:/anaconda3-2025.12-2/envs/pytorch/python.exe -m pytest tests/test_full_generative_report.py -q
```

最近完整结果为 **7 passed，17.92 s**。测试独立验算遮罩、逐站增益、站宏覆盖率与池化覆盖率的区别、距离箱端点及站对计数、缺高度跳过、未选候选忽略、同档只读取一次、point/joint 不同赢家、未评分位置非有限预测拒绝、固定种子重复性、站宏/微 RMSE 区别和整组重采样区间。

已查看实际生成的校准图和逐站精度/增益图，并修正共线小样本的地图坐标留白。年度规模的独立 CPU 基准采用合成 8760×110 数组，单个模型的两种块长、两种重采样与两项指标共输出 8 行，耗时 **0.578 s**，各行均为 2000 次有效重复。这是 CPU 算法基准；真实最终模型的指标由训练完成后的归档生成。

本次改动限定为 report 模块、对应测试和本报告；未提交服务器作业或执行 GPU 训练。
