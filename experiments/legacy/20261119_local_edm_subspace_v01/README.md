- [experiments/us/20261119_local_edm_subspace_v01/review/REVIEW.md](../../us/20261119_local_edm_subspace_v01/review/REVIEW.md)，第10行：- 固定查询矩阵记为 \(H\)，子空间行向量矩阵为 \(V\)。投影项 \(HV^\mathsf{T}\) 和余项 \(H(I-V^\mathsf{T}V)\) 由独立的标准正态随机流驱动，零步两项方差和为 \(HH^\mathsf{T}\)。地表未解析扰动保留独立随机流。空间项与地表扰动共乘冻结的A湿度尺度，发布的潜在格网只包含空间项。训练成员独立抽样，U-ES的成对项按 \(2K(K-1)\) 归一。训练保留采样器35次去噪计算的梯度。
