# 已有时序扩散与本项目：差异、可借鉴机制和下一步验证

日期：2026-11-25。性质：围绕现有架构的定向方法对照，选取8项代表工作，非完整系统综述。论文机制以原始论文/会议页面核查，本项目建议标为待验证。检索与来源记录见[来源清单](../../research/temporal_diffusion_review_20261125/sources.json)。

## 1. 判断

历史编码、Transformer条件扩散、均值加残差、标准化和自回归生成都有成熟先例。本项目应把这些作为方法依据，重点验证稀疏GNSS观测到连续空间场的编码，以及地形、海岸和连续历史对留出站与联合误差的作用。

当前设计见[掩码Transformer融合与标准化残差场](../superpowers/specs/2026-11-25-masked-transformer-fusion-residual-design.md)。它包含两部分：p14参考场上的时空特征融合；基础场冻结后的标准化创新扩散。后者目前通过固定逐通道AR连接相邻潜状态，diffusion学习每帧创新的多维分布。时间随机关联主要由AR承担，不能把它描述为扩散已经学会任意连续时空轨迹。

## 3. 本项目更具体的任务差异

### 3.1 稀疏站点到任意坐标

输入是变化的条件站集合，输出是隐藏站或任意查询位置，不是固定变量向量的下一帧。编码必须同时处理坐标、高差、距离、坡度、粗糙度、海岸与缺测。支撑网格是内部载体，查询集合不应反过来改变共同点输出。

因此可以借鉴CSDI的轴分解，却需要把固定变量标识改成空间位置与邻域关系。当前先采用16×16逐位置时间注意力与局地卷积；坐标边消息/局部空间注意力作为独立对照。双轴思想本身不作为本项目独有机制。

### 3.2 隐藏站历史不可当作已知观测

TimeGrad的预测对象通常有历史序列，本项目R任务的目标站在整个历史窗保持隐藏。历史条件只能来自允许站；生成端延续自己生成的残差状态。不能用真实目标历史运行TimeGrad，再将其分数和本项目隐藏站重建直接排名。

### 3.3 残差表示是实际瓶颈之一

CorrDiff直接监督密集格点残差；本项目只知道站点处的`r=y−mu_OOF`。残差编码器E与线性坐标读出Phi必须先通过站点重构、遮站和空间留出。只有这个表示足够准确，扩散分布的优劣才有明确解释。1 mm重构门槛是当前计划的工程门槛，不是已有实测成绩。

### 3.4 当前重建与未来预测分开

R任务允许条件站截至各帧时刻的观测，在线生成时新增条件可以进入后续帧。未来预报F则所有动态条件统一截止起报时刻，未来气象和真实GNSS都不进入条件。GenCast的预报口径不能直接替代本项目R的评价合同。

## 4. 最值得借鉴的改进

### A. 继续完善基础场内的时空交互

保持用户选定的因果Transformer，按现有T0–T5消融推进。借鉴CSDI的轴分解，在每层交替时间注意力与局地空间传播，再将时间状态送入p14的高/低分辨率残差解码器。相比只增加历史长度，这能直接检验“历史变化是否传递到对应位置的空间修正”。

先完成局地卷积版本；若复杂地形/远站分层仍无收益，再单独比较带坐标、高差和海岸边特征的局部空间注意力。避免全区域所有时空token两两注意力。

### B. 保留强均值，先完成可审计的残差标准化

沿用CorrDiff式分工，基础场mu留在扩散链外。全局`u=(r−b)/s`的b/s由允许训练残差拟合；不同空间折按单fold、单布局、单时间块形成事件，不拼成同一个伪残差场。共享条件编码器G避免各折隐藏通道含义变化。

GenCast也使用标准化动态差值，但其目标为相邻天气状态变化；这里首先拟合基础场误差。可以对照误差r与误差小时创新，而不能把两个目标混称成同一对象。标准化不消除生成误差，也不保证集合均值RMSE下降。

该归一化机制的具体来源为[GenCast方法附录D](https://arxiv.org/html/2312.15796v2)，其中明确区分物理状态变化与扩散噪声尺度。

### C. 将固定AR升级为条件动态，但保留原版控制

当前设计为`w_t=rho*w_(t−1)+be+se*v_t`，rho逐通道固定。它适合检验一阶时间随机关联，但不足以代表不同季节、天气过程下的复杂误差演变。

受TimeGrad和GenCast的条件演化启发，建议新增下列消融，均为待实现：

```text
V0：固定rho + Gaussian创新
V1：固定rho + diffusion创新                  # 当前设计控制
V2：rho(c_t) + diffusion创新                 # 只改变转移系数
V3：rho(c_t) + m(c_t) + a(c_t)*v_t           # 再加入条件位置/尺度
```

`c_t=G(允许信息≤t)`；`rho(c)=0.95*tanh(head(c))`。V3的位置/尺度头先按训练残差Gaussian NLL拟合，尺度有正下界，然后冻结，Gaussian与diffusion共享这些头。训练目标变换为`v_t=(w_t−rho(c_t)*w_(t−1)−m(c_t))/a(c_t)`，采样用自身上一帧生成状态严格逆变换。真实w历史只参与标签变换，不进入条件编码器。该形式是面向本项目合同的建议，不是对TimeGrad原公式的照搬。

V2/V3仍假设给定条件后的创新逐帧独立。它们拓展的是条件动态与校准能力，不直接等于任意时空联合扩散。各自增加匹配Gaussian对照，才能判断收益来自动态/尺度头还是创新分布。

### D. 用观测误差模型检验生成场的一致性

借鉴SDA的观测算子思想，另设`y_obs=H(field)+eta`，H为在条件站坐标的读出，eta为观测误差。可用误差加权的观测一致性诊断或采样引导，不要求生成场无误差地穿过全部观测点。噪声协方差由允许训练质控/误差资料估计，不能用2020隐藏站误差反推。

当前mu/G已使用条件观测，因此再次加似然引导须检查是否重复计入同一观测；SDA原始“先验＋观测似然”分解不能无条件套入已条件化的生成器。该项在基础场与残差模型稳定后独立验证。

### E. 延后长历史和频域损失

SSSD/S4作为168小时输入的效率对照，Diffusion-TS启发频谱/趋势诊断；现阶段先做残差的滞后相关、小时增量与天气过程分层。若引入频域损失，必须同时报告增量、峰值时刻和站对差值，检查平滑是否掩盖快速变化。训练时间仍连续遍历，不照搬论文随机抽时间窗的调度。

## 5. 两种mask必须分清

物理时间因果mask规定哪些真实观测能进入条件。噪声目标之间能否双向交流，则取决于生成任务的概率定义：

- 对R的逐帧创新生成，每帧扩散只处理当前创新，历史G因果；当前帧内部潜维token可以双向注意。
- 对固定起报时刻F的整块未来联合生成，所有条件统一截止起报时刻后，未来噪声帧之间可以双向交互，这不是读取未来真值。
- 不对相关的整块状态直接套严格三角epsilon网络，然后仍宣称使用其标准联合score。当前采用可逆创新变换规避该混用。

因此，“GPT式掩码＋diffusion”要说明mask作用在哪里。CSDI的补全mask与Transformer的未来mask也不是同一个对象。

## 6. 验证优先级与贡献表述

近期先完成基础场T0–T5及残差表示，随后V0/V1比较，V2、V3依次加入。每个生成方案均固定mu、条件信息、残差人口、历史窗、样本数和种子；报告实际预算。除点值外，比较fair CRPS、覆盖/宽度、小时增量与站对差值，并用成员shuffle与匹配Gaussian分开检验动态和分布收益。

可以研究并最终由实验支撑的贡献是：地形与海岸条件下稀疏GNSS到连续场的时空编码；跨站网/坐标查询稳定性；以及同信息条件下残差概率场对空间和时间联合误差的改善。Transformer、残差扩散、标准化和AR本身作为已有机制引用。

本轮不移植网络、不启动新训练，也不把文献成绩换算成GNSS毫米收益。原架构作为V1基线保留；本页新增V2/V3及SDA方向属于待验证建议。
