# 因果状态自监督与显式创新／增量传递

## 依据与目标

第一轮seed42、同源I1主队列中，六小时持久性宏RMSE14.985 mm，天气MLP14.414、GRU72为14.355、LSTM72为14.361、Transformer72为14.374 mm（均为raw最终3000块）。当前R约9.861–9.871 mm，对照I1为9.867690 mm；尚无明显R收益。原生时间模型对天气摘要MLP的额外收益较小，下一轮直接检验时间状态是否得到足够预测监督，以及物理观测值能否更有效地进入查询场。

## 因果下一状态目标

保持原始GNSS/T/P、mask/age、逐站模型误差、地形/海岸与身份输入，使用相同72h历史、宽64的GRU/LSTM/因果Transformer。对每个历史位置i及h=1…6，用该位置的因果隐藏状态预测同站i+h相对i的ZWD/T/P增量；只有i+h仍在已知历史内且两端有观测时计损失。尺度固定为10 mm、2 K、2 hPa，辅助权重0.25。

未来历史位置在Transformer中由严格因果掩码隔离，GRU/LSTM均单向。该目标使用训练窗口内部已存在的条件观测，不额外读取预报起点后的气象数据，不读取隐藏查询真值作为条件。它是连续变量的因果状态预测，与GPT的前缀预测共享监督组织原则。

## 显式值通道

在原有地形/海岸查询注意力上，四个头分别增加50/100/200/400 km高斯空间先验。每站先完成时间编码，仍保留方向、高差和海岸关系。

当前校正直接传递过去0/1/3/6/12/24h的已知站点创新`GNSS−I1同位置预测`，按3km尺度作高程输送，再由零初始化的查询门控组合；观测缺测时不进入相应滞后权重。

未来分支在每站最后状态预测未来1–6h的GNSS增量，按同一地形/海岸注意力传递到隐藏查询；所有未来值均为模型预测。未来传递门初始1、站点预测头初始0，查询残差头及当前创新门初始0，因此初始化严格等于I1当前场和起点持久性。当前修正仍限制±5 mm、未来±30 mm。

## 对照设计

Transformer72执行2×2对照：仅局地先验、局地＋因果辅助目标、局地＋物理值通道、局地＋两者；每臂相同初始化和3000连续训练块。完整方案再对比GRU/LSTM，保持输入历史和监督组织一致。比较新增机制与原Transformer72、天气MLP、I1；raw/EMA均归档，不把同轨迹权重计成独立重复。

R与F分别晋级；双种子和冻结补充日期后再判断明确收益。若出现收益，再比较归一化查询头或相近容量控制，识别增益来自值通道、辅助监督还是优化尺度。随后用冻结均值场构造标准化残差，比较匹配Gaussian、相关Gaussian、空域/完整谱v及Gaussian预条件v。

代码采用独立变体文件保留原实现和已有结果；确认/C/D、原始数据和历史科学锁不变，仍标注非严格OOF。
