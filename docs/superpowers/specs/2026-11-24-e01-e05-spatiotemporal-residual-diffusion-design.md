# E01–E05 时空地形残差扩散实验设计

日期：2026-11-24

## 目标

在现有 p14 固定支撑编码器和 P15 hole100 采样合同上，逐步加入地形特征、显式测站边消息、时间条件、时间增量损失和残差扩散，判断前五个机制能否在统一扩展评价中降低 ZWD 场误差，并保持时间演变连续。

## 约束

- 数据区域和时间保持美国西部 2016–2020；训练/验证站沿用 410/137 合同。
- 不使用 PWV、IWV、TCWV 等水汽柱变量；ERA5 仅使用站点可获得的同口径气象变量。
- C/D 确认标签不参与训练或调参。
- 每个实验独立编号、独立目录、独立 seed42/17 结果；权重和大型数组留在本机，轻量指标、报告和代码同步 GitHub。
- 正式指标沿用 p14 扩展评价：宏 RMSE、微 RMSE、MAE、Bias、CRPS、P90/P95、小时增量宏 RMSE；同时报告地形/距离分层结果。

## 方案与顺序

- E01：在现有查询和测站特征中加入可学习的地形/海岸距离编码，其他结构不变。成功判据：相对 p14 平均宏 RMSE 至少下降 0.2 mm，且三布局不出现系统性恶化。
- E02：在 E01 基础上加入显式空间边消息（距离、方位、高差和邻接权重）。成功判据：宏 RMSE 和远离测站分层 RMSE 同时改善，小时增量不恶化超过 0.1 mm。
- E03：加入相邻时刻的条件编码，使用轻量时序模块，不改变空间解码器。成功判据：小时增量宏 RMSE 相对 E02 下降至少 0.2 mm，绝对宏 RMSE 不恶化。
- E04：加入小时增量损失，与场值损失联合训练。成功判据：时间增量指标下降且 Bias、P90 不恶化；若绝对宏 RMSE 上升超过 0.2 mm则停止该分支。
- E05：用基础场输出作为条件，让扩散分支预测残差；先做短训 smoke，再做两 seed 正式训练。成功判据：宏 RMSE 相对 p14 下降至少 0.5 mm，且 CRPS/空间分层指标同步改善。

## 评价设计

每个实验先运行 5 秒 smoke，检查数据合同、前向、反向、保存和评价器；通过后运行约 120 秒短训筛查，只有优于当前候选才进入 600 秒续训。所有比较固定随机种子、layout、采样站群和评价时段。结果写入 `results/20261124_<experiment>_<variant>/`，并生成 `REPORT.md` 与 `metrics.json`。

## 非目标

本轮不同时引入 Transformer、XGBoost、超大 U-Net 或新的外部数据；不把 monitor RMSE 当作正式成绩；不因短训波动宣称达到 8 mm。

## 待实现

复用现有数据加载和扩展评价器，新增一个最小联合模型入口及实验配置；每完成一个实验即进行代码审计、指标核验和 GitHub 同步。

## 锁定的执行合同补充

- 基线固定为 p14 formal protocol；E01–E04 同时跑 p14-compatible random 控制与 hole100 臂，E05 只在 hole100 上跑。每个实验 seed42/17 均完整运行，smoke 仅做工程检查，不参与筛选。
- 训练/验证和 3 个 layout、12×24 小时、缺测掩码、宏/微聚合均直接读取 p14 protocol JSON 与其 hash；实现不得重新定义评价集合。
- 地形特征来自当前项目已制备的站点/查询点地形表，使用项目锁定的数据版本和 hash；经纬度为 WGS84，高程为项目现有基准。归一化统计仅在 410 训练站拟合，缺失值使用训练集中位数并记录缺失率。
- E02 使用固定 k=8 空间邻居；边特征为球面距离、方位角正余弦、高差，全部使用训练集统计标准化，权重为 exp(-distance/median_distance)。目标查询点只接收测站消息，不反向写入测站状态。
- E03 仅使用 t-1 和 t-2 历史条件；跨日和缺测按序列边界切断，不使用未来值。时序模块为单层 GRU，hidden=64，参数预算不超过 100k。
- E04 采用预测场差分与真实场差分的 Smooth-L1，配对掩码要求相邻两时刻均有效，权重 lambda_delta=0.2；不等时距样本不参与增量项。
- E05 基础场冻结，并用训练折内 OOF 预测形成残差条件；残差扩散预算、采样步数和评价协议与 p14 formal 固定，避免同样本拟合泄漏。
- 成功判据均按两 seed 均值与逐 seed 同时报告：宏 RMSE 至少下降 0.2 mm 才算 E01–E04 有效，E05 至少下降 0.5 mm；小时增量改善至少 0.2 mm，其他主指标允许上升不超过 0.1 mm。地形/距离分层按四分位边界预注册，最小有效样本数为 1000。
- 不根据 120 秒结果淘汰正式实验；screen 只验证可运行性，正式短训和续训臂预先固定。报告记录 protocol/hash、数据/hash、步数、失败状态和 C/D 未读取审计。
