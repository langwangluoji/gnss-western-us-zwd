# 均值表征到概率条件的信息直连

## 实测依据与假设

seed42冻结联合Transformer后，训练当前残差在<50/50–100/100–150/150–300km档RMSE为7.460/10.187/12.105/15.042 mm。当前Gaussian在开发相同距离档预测标准差RMS约8.38/8.41/8.83/8.40 mm，150–300km解析80%覆盖59.57%。训练中该档有360641个当前标签，并非没有相应几何范围。见`maintenance/weather_native_20261126/residual_geometry_audit_s42.json`及Gaussian校准审计。

现有概率头只读冻结均值模型的64维融合状态。该状态为均值损失训练，不能预设其对条件残差分布也充分。先检验原始因果查询信息的可访问性，再考虑扩大score网络或增加新的天气变量。该假设尚待配对训练验证。

## 四个Gaussian条件对照

冻结同一个Transformer均值、缓存、训练统计及0–6h残差，保留当前Gaussian架构类别：

| 名称 | 条件 | 隐藏宽度 | 参数量 |
|---|---|---:|---:|
| L64 | 原64维融合状态 | 64 | 5070 |
| R111 | 原始111维因果查询向量 | 64 | 8078 |
| S175 | 64维状态与111维原向量直连 | 64 | 12174 |
| Lwide | 原64维状态 | 154 | 12180 |

S175与Lwide相差6个参数，检验增益能否由增加容量解释。111维向量只含过去和当前的创新、背景变化、GNSS/T/P摘要/覆盖、地形/海岸、日历及最近可见站距离；不含目标真值或未来观测。完整逐站时序仍通过原64维状态保留，R111只作信息来源消融。

四者各3000连续块，先seed42，再对形成明确收益的条件视图复核seed17；L64直接复用既有训练，不重跑冒充新重复。raw/skip视图按块从既有缓存组合，不生成新的大型数组。

## 与扩散连接

概率工厂显式接收条件维度和隐藏宽度；旧latent/64默认保持原函数。若S175或R111在同缓存及容量控制下改善校准或CRPS，后续Gaussian、空域/图谱/频率token v与预条件v使用同一获选视图，区分条件信息收益和分布族收益。

预条件Gaussian与score必须读取同一条件视图，宽度和来源哈希登记在协议，禁止静默切换。当前均值和原模型文件保持冻结；新增视图只作用于概率阶段。新结果仍为2020已暴露开发、非严格OOF，确认/C/D隔离。

## 判断依据

独立复算fair CRPS、解析Gaussian均值/80%覆盖、有限K秩区间、站对及预报内部增量，重点检查150–300km、近海和夏季。S175对Lwide的比较是本轮核心信息瓶颈检验；R/F和概率结果分开。未达到既定明显收益门槛时继续依据数据诊断，不将参数增加或区间变宽本身视为发现。
