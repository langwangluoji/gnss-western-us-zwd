# 天气条件、长历史创新与原生站点时空扩散

## 目标与当前证据

以已验证的GRU+p14＋I1为当前重建R的同口径对照（主日历9.817064 mm），探索天气条件和长历史创新、原生站点上的残差联合分布及未来1–6h预报F。用户授权自主选择并运行方案，新增研究在账户剩余额度75%时停止。2026-11-26读取额度为剩余87%；阶段间及大批量工作前复核，预留结果核验和Git同步。

已有频域证据：旧100步工程小试L1历史谱条件比L0有更小误差；规则256锚点自重构误差6.85/8.61 mm，几何适应支撑自重构改善，但空间组留出仍约20 mm。epsilon高噪声端幅度放大；v预测改善数值稳定性。这些均非新I1基础场上的收益。

## 路线选择

1. 在旧规则锚点上继续扩大diffusion：会混入表示损失，暂不采用。
2. 原生站点残差＋天气/历史条件＋v扩散：主路线。直接学习查询站的0–6h残差，不将标签投影到格网；当前空间重建与未来预报分开报告。
3. 完整时间DCT及图Fourier的联合模型：与主路线配对的表示对照。正交变换保留全部系数，先验证可逆和能量，再检验网络归纳偏置。变换本身不提供额外观测。

路线2/3为代理依据既有证据作出的实现选择；保留确定性均值和Gaussian对照。没有先验保证某类diffusion最好。

## 架构

### 用户补充的必做时间编码对照

下一版逐站编码冻结源模型误差、原始GNSS ZWD/T/P、三变量mask/age、日历及地形/海岸关系；条件站身份、坐标与方向在时间编码前保留。GRU、LSTM、带严格上三角因果掩码的Transformer使用相同72h有效状态历史、宽度64和共享查询模块；另做24h历史控制，预算允许再扩168h。条件身份只作为可见站token输入，隐藏查询不使用目标站专属学习参数。

每站时间状态先独立编码，再由目标静态/天气状态生成query，地形/海岸/高差/方向作为多头注意力的边偏置和边值，传播至隐藏目标。新增7维均值头零初始化，第0维保持I1起点，第1–6维保持起点持久性；模型训练后报告它们的单独收益。随后固定均值头，训练同条件的Gaussian与diffusion，区分基础场提升和概率模型提升。

72h校正后站点状态需要146h原始观测跨度，24h需98h；缓存保存83帧（72+12−1）逐站状态，每块的条件身份贯穿源模型预热和整个状态历史。缓存不拼接不同条件集合的前块隐藏状态。所有模型从同一最长合法状态缓存取后缀，确保历史和标签可比。

查询辅助向量还使用24h前的校正背景，因此24h状态臂的整体信息跨度为99h（该辅助状态含当前和24h前两个端点）；72h状态臂仍为146h。各时间模型同一历史臂共用完全相同的辅助条件。

条件站GNSS/T/P → 冻结GRU+p14 → 同站创新 → 0/1/3/6/12/24h创新及背景趋势、天气与覆盖编码 → 查询点条件向量。

I1起点均值 → 共享点条件均值头（预测0–6h修正，零初始化）→ 条件Gaussian均值/尺度；残差用训练统计标准化。v扩散在相同条件下预测7h×查询站残差，单一状态、单一噪声、单一反向链。空域用坐标图消息；图谱模型在同一图上使用完整特征向量与频带滤波；时间DCT保留7个系数。所有模型输出回到同一物理单位mm，固定采样预算比较。

原生图随目标站集合构造，需报告查询数量变化的敏感性；这属于联合分布模型的诊断，不能把不同查询人口的分数混排。训练128目标和开发137目标的分布差异单列。

## 实验与晋级

W0：I1复现；W1：增加背景趋势/长历史；W2：再加ZWD/T/P天气和覆盖。先检验原生特征是否提供可学习条件信息。P0：匹配Gaussian；P1：空域v；P2：全图谱v；P3：时间DCT×图谱v。每项至少3000神经更新；先一个种子找工程问题，晋级候选必须两种子及冻结补充日历。

P0另有相关Gaussian控制：同一条件边际网络，训练残差二阶矩拟合空间RBF混合强度与7h时间相关矩阵，时间矩阵5%单位阵收缩；不读取开发标签。相关采样的每个边际方差保持1，成员间使用独立白噪声，fair CRPS的IID前提成立。

W1/W2的`--no-weather`仅表示是否加入额外的显式查询天气摘要；冻结I1源本身已含T/P。该开关限定用于weather MLP，不能称为全模型移除气象信息。

### P4：天气条件Gaussian预条件与保参考采样

先冻结P0的条件位置μG(c)与尺度σG(c)，再令z=(r−μG)/σG训练v扩散，最终以μG＋σG·z恢复。该可逆仿射映射将天气/季节相关的残差尺度交给Gaussian，扩散学习条件分布相对Gaussian的偏离；不使用开发真值缩放。

采样增加同一v网络的Heun概率流控制。设xθ=cosθ·z＋sinθ·ε，则vθ=cosθ·ε−sinθ·z，概率流速度为E[vθ|xθ,c]。标准白Gaussian参考下该条件速度为零。有限步确定性DDIM在零速度时每步仍乘cos(Δθ)，会收缩参考方差；Heun直接积分θ上的速度，零速度时精确保持参考样本。该性质先由测试和数值算例验证，再在真实GNSS上比较校准与CRPS，不将数值恒等式称为精度发现。最终比较DDIM40与Heun20，各40次网络调用；另保留旧DDIM20诊断。

### P5/P6：具有实际频域结构的完整频率token

P3只在全连接输入/输出之间加入完整DCT，其函数类可由首尾线性层的正交重参数化实现，主要是优化坐标对照，不能据此宣称新增时间频率能力。P5将7个时间频率分别保留为token；每个token接入相同天气/时间状态、频率位置及扩散步，使用完整图Fourier滤波传递空间信息、深度可分离的3频带邻域卷积传递频率信息。共享非线性逐频处理，最终全部系数逆DCT，仍是一条v链。其参数量与原图谱去噪器相差不到5%，实际算时单报。

P6是在同一频率token架构上采用P0天气条件预条件。若diffusion出现收益，追加相近参数量Gaussian或条件相关Gaussian，区分分布族优势与容量/协方差建模的贡献。进一步完整协方差预条件作为后续候选，不在本轮未训练时宣称有效。

R要求双种子点RMSE改善、月份配对区间支持、小时增量不明显增加；以主/补充日期均有方向一致的≥0.3 mm或≥3%改善作为本轮“明显点精度收益”目标。概率模型要求相同均值/条件/成员数，fair CRPS至少相对匹配Gaussian改善5%，并检查覆盖、站对差值及时间增量；单靠CRPS一项不能宣称全面领先。F分别报告1/3/6h对I1持久性及天气条件确定性头的收益。

结果如未达到阈值，记录诊断并根据证据优化；达到额度阈值则停新增实验，保留未完成项，不把停止称作突破。图件、报告、协议、指标和哈希入Git，数组/权重仅本地。
