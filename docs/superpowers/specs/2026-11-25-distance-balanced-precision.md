# 距离分布匹配：提高时间—空间残差分支的有效训练比例

## 证据与假设

重放每种子全部3000个连续训练块并逐小时检查当前有效条件站后，随机训练目标约59.4%位于条件站50 km以内。75%随机＋25%100 km空洞布局将该比例改为58.7%，改变较小。相比之下，137个开发坐标与3个固定条件布局构成的411个纯几何样本中，50 km以内占16.30%，50–100 km占51.34%，100–200 km占28.95%，200 km以外占3.41%。后者只使用坐标，不读取开发真值或真值可用性。

新增残差头的大部分有效训练目标来自近条件站位置，而评价更多来自50–200 km位置。本项由代理设计为损失重平衡对照，检验这一距离边际差异是否限制新编码的收益。

审计数据见`results/20261125_support_distribution_audit/results.json`；可运行脚本为`maintenance/joint_spectral_implementation_20261125/support_distribution_audit.py`。

## 固定权重

训练分母取S臂75/25布局的双种子记录比例均值；目标分子取上述纯几何比例。比例相除后固定到小数点后三位：

| 到最近当前有效条件站的距离/km | 权重 |
|---|---:|
| 0–50 | 0.278 |
| 50–100 | 2.297 |
| 100–200 | 1.922 |
| 200及以上 | 0.879 |

边界50/100/200 km进入右侧区间。若某小时没有当前有效条件站，采用最后一档权重，仍保留该小时的有效训练目标。权重只依赖条件可用性和查询坐标。训练标签继续按原物理组遮挡规则使用。

主项为`sum(w*error^2)/sum(w)`。相邻小时项使用两时刻权重均值，仅对两时刻目标都有效的位置计算，再乘原0.1系数。评价指标和人口保持原定义。该方法重平衡距离边际，不宣称消除全部地形、天气及空间分布差异。

每个12小时块分别归一化。独立CPU重放的水平损失权重占比，seed42为16.47%/51.11%/28.92%/3.50%，seed17为16.41%/51.13%/28.99%/3.47%，接近目标几何比例。实际梯度还取决于预测误差和模型导数，权重占比不等于梯度占比。该配置使用已知开发几何适配训练，正式结论限定在这一已暴露开发合同。

## 唯一训练改动与对照

网络与原始站点S臂相同：冻结完整GRU+p14，新增逐站72h因果Transformer32、查询交叉注意力、原U-Net双尺度和±5 mm残差头。第一维仍为原始ZWD标准分数，使用原mask；本臂不使用A的空间异常时间输入。

训练2016–2019连续小时、12小时批、每条3000步、seed42/17、AdamW lr1e-4、EMA0.999，条件布局与S臂相同。所有新增头零初始化，起点等于各自旧参考；只改变训练损失的距离权重。预先登记最终raw与EMA，两者共享训练轨迹。

入口为`station_query --loss-mode distance`，新目录`20261125_station_distance_precision`，结果标识`D_transformer_raw/ema`。原S使用Git `dd24a9a`，A使用`1bb1e0f`所含模型代码，D另记本次代码哈希；旧进程和旧协议不改写。

## 验收

正式结果保持2020每月72h×3布局×137登记站的开发合同。先配对同种子原参考，再直接配对D_raw−S_raw及D_ema−S_ema，使用相同月份重采样。重点报告50–100/100–200 km及近海、高粗糙度、夏季的变化，同时核对近条件站误差和小时增量。晋级仍要求双种子一致、月份区间支持，以及增量容忍线；确认集/C/D保持隔离。

CPU测试验证当前有效观测选择、距离分档边界、无当前条件的退化、单位权重恢复原目标、增量加权及缺测屏蔽。D完成后再决定是否需要更多训练轮次或联合微调。
