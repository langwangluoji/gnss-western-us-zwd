# 独立双场差分：均值保持与概率收益诊断

## 问题与原理

新Local相对天气G265/Affine有较小概率收益，当前均值MSE相对基础场仍增加。先用不改权重的诊断判断：移除生成分布均值修正后，其相关结构与对称非Gaussian部分是否仍有价值。

给定相同可见条件c，令X、X'是条件独立同分布的完整场，且有有限二阶矩。定义

`Y = mu_base + (X-X') / sqrt(2)`。

则`E[Y|c]=mu_base`，`Cov[Y|c]=Cov[X|c]`。该操作使分布中心对称；在相应高阶矩存在时，奇数阶累积量为零、四阶累积量减半。它改变分布形状，不等于恢复原扩散分布或保证概率评分改善。

## 已授权的执行选择

用户已授权自主设计并实际检验残差扩散融合。采用已有冻结样本作低成本诊断，不训练或改写原模型/科学锁。原32个IID场按固定规则配成16对：`(k,k+16), k=0..15`，不同输出成员使用互不重叠的输入。每个场的所有站点及时效共享同一配对，保留完整场协方差结构。这个配对在读取新分数前锁定，不按开发标签选择配对。

Gaussian参考、Affine、Local均同样变换并以K16比较；主来源为G265与其Heun0连接，双种子。另给出原模型前16成员的匹配K控制，但原始中心与新中心不同，因此该对照用于描述变换的影响，不能只归因非Gaussian。DDIM作为独立复核，主判据不根据采样器成绩切换。

## 数据与评分

沿用2016–2019训练来源、2020每月8–10日已暴露开发、三布局137查询。仅读取已归档冻结预测及允许开发truth；确认与原C/D标签保持隔离。不使用PWV/IWV/TCWV/Tm。

评估单站CRPS、四档站对差值、固定起点内部增量、全场energy、10/20/30mm事件和主20mm两方向。所有fair校正使用实际K16。K16区间覆盖与K32第3/30统计量不混用；本诊断采用第2/15顺序统计量，连续校准IID参考为13/17。

解析点输出为原mu_base。K16样本均值继续单列有限成员误差；不能将有限集合逐站减均值后误称IID。数学均值/协方差性质须通过独立有限分布枚举核验，再做真实GNSS评分；原始预测/权重不覆盖。
