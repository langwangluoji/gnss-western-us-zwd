# 逐站留出创新的真实审计

## 科学问题与阶段

比较自条件创新、留单站创新、留空间组创新的尺度及对隐藏查询误差的关联。背景均为同一已训练p14＋GRU，原TF3000作隐藏目标残差参考；先核验工程与成本，再扩大诊断人口。此阶段不训练新神经模型、不改变连续训练合同，选取固定缓存块仅用于信息诊断；不能将诊断日期成绩当作3000步新模型成绩。

## 计算合同

对原条件站集合C，在每个待诊断起点及其0/1/3h历史计算背景：self使用C，LOSO对站j使用C\{j}，LOGO对所属空间组G使用C\G。留出在背景所需全部72h历史及当前GNSS/T/P输入上生效。各方案最终创新使用相同可见站当前观测，背景预测本身不能读取被留站观测。

8个空间组只由条件站坐标和物理站组构造，确定性最远点中心＋最近中心分配，同物理组保持同折。单站留出则明确只留该站，不假定等于物理组留出。

query身份、原背景源、固定TF预测、truth及mask不变。查询在原条件物理站组之外；确认及原C/D隔离。允许Z0/T/P，原包未来可用性选目标、历史PWV质控和strict_oof=false限制保留。前向留站不等于训练折外，背景权重仍使用原2016–2019拟合来源。

## 数值与信息核验

1. 折分不读标签，确定性、物理组完整、每站恰属一组，留出后C非空。
2. 原self背景创新与缓存history通道9×10一致（float16存储容差）；超差即停，不将来源漂移解释为新收益。
3. 对一个留出站，改变其背景依赖窗内观测后，该留出背景预测逐值相同；恢复内存数据。只扰动内存，不改原数据文件。
4. 记录LOSO和LOGO的实际调用次数、耗时、创新RMS及尺度比、预测传递特征与目标残差的关系。将LOSO各站不同条件集合的误差并列使用属于编码候选，不能直接当作同一联合Gaussian过程。
5. 保存本地原数组、轻量汇总、源权重/源码/cache/导出哈希；无实际收益前不改正式基础场或残差扩散源。

## 首次工程测量

seed42原train缓存第0块，前两个连续起点加三小时历史，全部82站LOSO和8组LOGO；完整C控制。固定这一测量规则后再读取新结果。后续人口及诊断/拟合/验证角色依据实测成本另立锁，不根据开发分数选日期。
