# 最佳有向基础场与残差扩散的匹配融合

用户在阶段收束后新增授权：结合当前最好的基础场与扩散模型，构造融合模型并实测效果。这是新的有界实验，不重启上一目标的无限优化。旧合同、锁、权重与成绩保留。

## 选择与架构

采用已验证joint v2/raw final3000（双种子）作冻结确定性载体，主当前9.806169、F6 13.852222mm；I1作为当前重建的稳健参考，joint作为当前最好的预报载体。沿用全部站点/历史条件，以新joint权重重新导出训练嵌入、七小时预测和训练残差统计。

不直接把旧扩散修正加到新载体：旧尺度、相关核与扩散由TF3000残差拟合，来源不匹配。此轮也不联合更新均值与扩散：冻结载体使概率评分变化可以归给概率分支，点预测精度能逐值核验。

冻结joint → S175条件Gaussian新拟合 → 训练残差矩copula → G265天气相关核新拟合 → 同起点/条件/预算的Affine与Local v扩散。所有神经模块复用已验证实现，不修改旧源码。Gaussian允许自己的残差位置校准；独立点输出始终为joint。概率中心与确定性点输出分别报告。

主输出为K32 IID原始生成场。另对同一模型的不重叠独立成员对构造K16中心保持场：

`Z_pair = mu_joint + (Z_2k - Z_(2k+1))/sqrt(2)`。

条件期望严格为mu_joint，协方差等于原生成场；偏态被对称化，不宣称保留全部高阶结构。Gaussian/Affine/Local均做相同差分对照；不对同一成员集合减样本均值。实际K16成员均值仍有采样误差。

## 主比较与验收

主比较是新Local−同源Affine的F6 fairCRPS，两种子等权、2000次共同月份重采样；两日历分别报告。二级指标包括当前CRPS、内部增量CRPS、近邻/远距站对差值CRPS、energy、20mm增湿/减湿Brier、有限成员秩覆盖、负值比例和均值漂移。中心保持K16只与同K的匹配对照排名。

点场必须与原joint评价逐值相同。报告确定性RMSE、采样均值RMSE与扣除采样方差后的均值MSE估计，不能把概率收益当成RMSE改善。记录高程/海岸/条件站距离及重点站的变化；保持模型来源。
