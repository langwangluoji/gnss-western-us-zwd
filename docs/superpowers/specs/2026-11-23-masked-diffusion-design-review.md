# 本地设计复核与修订记录

2026-11-23，按brainstorming的builder check要求，由独立只读审查者检查主设计。该审查是本地代码代理审查，不是网页协作，也不是实验成功证明。

初审提出5个重要问题，设计已逐项补齐：

1. 缺测目标没有x0，不能填零后参与带噪图：基础去噪只抽当前有效目标子集；自由生成固定查询集，缺标签只屏蔽评分；padding同时从图和attention隔离。
2. B-fit真历史与A唯一观测边界：明确teacher forcing是训练专用目标状态接口；验证禁止真历史，初始缺历史或自身生成。基础50%真历史/50%目标历史屏蔽，微调100%自由历史。
3. 4h×K4×20步可微链成本：明确完整CRPS反传、辅助v路径历史stop-gradient、检查点、实际前后向profiling和OOM降级顺序。
4. 12h历史与旧30h包不一致：从A包补取更早小时，新缓存/哈希，保持24h评价人口。
5. 查询布局与门槛：先固定77站集合，增加77/308个查询点做共同噪声配对及独立采样检查；定义均值/离散度/评分漂移门槛。格网分块只允许保留全局逐层消息，不独立拼接。

另外澄清P4更新数按每候选×种子×空间折计算。初审确认宏/微RMSE与fair CRPS公式正确，角色、C/D暴露和无稠密真值边界清楚。修订后的架构仍需P0/P1实测验收，尤其是训练子图到固定查询图的迁移、4h到72h自由滚动及整条可微链显存。

定向复核结论：上述修订通过，未发现阻断制定实施计划的矛盾。剩余迁移、滚动偏移和吞吐问题已转化为实验验收事项。复核未执行训练或网页审查。
