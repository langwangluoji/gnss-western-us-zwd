# 保留原始站点序列的连续查询残差编码

依据用户“未优于既有约10mm则持续优化”的授权，保留GRU+p14全部权重作为参考，自主检验更完整的稀疏观测编码。

## 起点与方案选择

T2_frozen seed42最终9.99658mm，T5_frozen为10.00607mm，原参考9.99836mm。查询级Qraw为9.99753mm，Qema为9.98229mm，第二种子尚在验证。扩大汇总时间编码器尚未带来明显新信息；EMA对连续训练有初步帮助。

可比较路径为：继续扩大栅格时间网络；把栅格状态放到查询点读出（Q，正在训练）；直接编码原始条件站序列。本轮选择第三条作为下一项性能实验，前两条保留为真实对照。此选择由代理作出，目标是检验站点身份、方向及高差信息是否在汇总中损失。

## 输入和模型

1. 条件仍为82/410个训练站，整段72小时和12小时目标批保持同一站集合。只使用ZWD、T、P、mask、ZWD观测年龄、日历和静态地形/海岸。
2. 每站逐小时11通道：原归一化ZWD/T/P三维、三个可用性mask、一维log-age、四维日历；另有8维站点静态信息。每站保留独立时间序列。
3. 站点时间编码器可选GRU32、LSTM32或两层四头宽32的因果Transformer，FF64。原始序列只在同站内部沿时间编码，输出当前32维状态；不先投到二维格网。
4. 对每个查询点，从有ZWD历史的条件站中取最多16个邻站。边特征10维：dx、dy、距离、高差、海岸差、按3km尺度显式输送到查询高程的ZWD与参考差值、age及三维地形差。所有高度显式用m，距离用km。
5. 查询向量来自原点特征113、静态9、参考均值1，以及冻结U-Net两级特征16＋32在查询处的读出，共171维。两级分别LayerNorm，避免原始幅度不同而相互压制；低级按原像元中心规则上采样。查询-站点交叉注意力联合站点时间状态与边特征，另使用距离先验；查询/键也归一化。获得32维局地状态和1维加权物理创新。
6. 拼接共204维，204→64→64→1，零初始化末层；新增物理修正限制±5mm。原p14 U-Net提供区域背景和多尺度状态，原始站点新分支直接在任意查询位置解码。

所有邻站编码、距离和消息只依赖条件站及该查询坐标。增加查询不能改变既有点输出。无有效ZWD历史时新增修正为0，退回原参考。

## 训练与评价

原参考冻结；新增lr1e-4，MSE＋0.1小时增量MSE，连续2016–2019、12小时批、3000步、seed42/17。先运行Transformer32。GRU/LSTM实现与因果性单测完成，是否追加正式训练按该臂结果决定，不预报未运行成绩。

为覆盖开发站的较大条件距离，站点布局按75%随机、25%训练站中心100km空洞抽样；时间不抽样。每四个连续块用独立布局种子随机指定一个空洞位置，避免固定每四步一次而与昼夜时段锁相；3000块恰有750个空洞块。布局与架构同时改变，作为整体性能候选；后续归因需随机布局单因素控制。

预先登记最终raw及EMA0.999，两者来自同一轨迹，只平均新增参数。评价仍为原2020每月72小时×3固定布局×137登记开发站。对齐原参考真值与权重哈希，检验宏/微RMSE、MAE、bias、增量、季节、地形/海岸/距离和站对差值。2020为已暴露开发，不称盲测。

严格OOF与残差扩散另行重建；本臂源权重已经见过2016–2019训练标签，不作折外来源。当前GPU已有两条正式训练，新增队列等待Q完成后启动，不额外挤占显存。
