# 完整图扩散的联合Gaussian机制控制

## 实测触发

seed42同S175、同冻结均值和相关Gaussian参考：Full Heun0的0–50km站对F6差值CRPS为4.464031mm，G-ref为5.244664mm（约14.9%改善）；50–150km为7.385957对7.925229mm。边际F6 CRPS由7.817942增至7.917516mm，fair energy由8.575740增至8.691908mm。Local的整体分数较稳，但近邻站对收益较小。该现象首先指向空间依赖结构，尚不能归因为非Gaussian性。

## 假设与对照

原Affine逐查询运算，空间耦合来自固定GP初值，无法作为Full非线性的充分机制控制。新增GraphAffine v：固定可见条件c、扩散时间k和查询图后，速度场严格仿射于完整查询状态。它允许跨查询、跨7h轨迹的条件Gaussian空间依赖，使用Full相同的全空间/时间白化、图谱滤波基、精确噪声端点和采样器。

网络：c175与clock5 → MLP宽79、两隐藏层 → 两层各154系数（7偏移+3×7×7矩阵）。第一层为`h=x+b0+Σ A0_l(c,k) G_l x`，第二层`v=b1+Σ A1_l(c,k) G_l h`；`G_l=U diag(1,exp(-λ),exp(-4λ)) U^T`。系数末层全部零初始化；初始h=x、v=0，无零梯度死路。参数45259，对照Full45639。固定条件下Heun0/DDIM保持仿射映射，故输出为联合Gaussian；条件网络本身可以非线性。

## 数据与执行

1. CPU测试先RED再GREEN：非零权重的速度与采样仿射性、零速度继承Gaussian参考、梯度、参数数目。
2. 独立适配入口仅在自身Python进程中替换现有严格runner的模型工厂和代码清单；复用源/数据/归一化guard、缺测分组、共同噪声及评价。协议额外登记family=graph_affine，源码哈希含模型和适配入口；不改既有runner或进行中的实验代码。
3. 同真实缺测3块各4更新，通过后seed42正式3000连续块；同Heun0×20（39NFE）及DDIM40评价。
4. 比较R/F6边际、预报增量、站对差值和fair energy；对局地站对比较给共同月份区间。按固定方案复核seed17。原确认/C/D保持隔离，2020已暴露，strict_oof=false。

若GraphAffine能复现Full站对收益，优先解释为空间Gaussian依赖建模；若Full有额外收益，再结合尾部与区域结果检验非线性作用。此控制不保证查询子集分布一致性；Local的共同GP路径一致性作为另一能力独立评价。当前没有将15%站对收益写成整体场精度提升。
