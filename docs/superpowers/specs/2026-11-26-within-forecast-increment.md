# 同一起点内部增量监督：固定H架构的损失消融

## 假设

保持已有H网络和同起点续训合同，通过新增h0…h6内部增量监督，改善六小时预报轨迹。原损失已有相邻起点h0差分0.1；本轮新增的是同一起点内部的六个差分。用户已经授权自主实验及同步，按既有研究分支原位执行；不另建缺少原缓存依赖的工作树。

## 冻结比较

- 控制：已有`20261126_mean_fusion_v2/H_s42,H_s17`，各自源TF3000继续3000。
- 新臂：相同`NativeMeanFusionV2('H')`、源checkpoint3000、初始化创建次序、AdamW moments/RNG、旧/新lr 1e-4/3e-4、cosine3000、aux0.25、EMA0.999。只改变query损失。
- 新损失：原mean_loss＋0.5×内部增量损失。以10mm归一化误差作同一起点最后维差分，使用相邻标签联合mask及原站点权重；每lead分别归一化后对六lead取均值，无有效标签lead贡献零。0.5事先固定，不按开发结果调权。
- 两种子42/17，原2016–2019连续块0..2999，仅站点抽样；旧末91块复用、未来可用性选目标、历史PWV质控及非严格OOF限制保持，与控制匹配。72h状态/146h原始依赖。
- 主评价2020每月8–10日三布局137注册查询，raw final3000主、EMA并列。新增结果不得改变已封存H/HS源码或权重。确认及原C/D标签继续隔离。

## 判断与归因

主要检验同起点内部增量micro RMSE相对H的双种子共同月份差值；同时检查当前/六小时站宏RMSE、跨起点当前增量及距离/海岸/季节分层。新增控制和数据来源必须逐值一致，不能把原模型额外训练的收益归给增量损失。

若主日期有收益，固定final权重后按原冻结15–17日补充日历评价新臂和匹配H；未完成补充验证前不宣布晋级。区间条件于两个固定种子、开发已暴露，探索比较未经多重校正。误差不改善或产生代价同样归档。
