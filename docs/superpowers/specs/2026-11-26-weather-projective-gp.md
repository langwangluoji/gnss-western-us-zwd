# 天气条件、查询集合一致的时空Gaussian先验与轨迹扩散

状态：CPU数学合同与真实缺测小试已实现；按lead长度细化后待正式3000块验证。用户已授权自主设计和运行后续实验；采用现有pytorch环境与本机RTX4060，不提交收费服务器任务。

## 实测依据与路线选择

Full图扩散的近邻站对F6差值CRPS在两种子约改善15%/13%；GraphAffine联合Gaussian控制也复现约11%的收益。Full的边际CRPS和fair energy有代价。Local逐站非线性相对逐站Affine的边际收益区间跨零；其优势是查询集合一致。证据优先指向可变空间依赖，再检验非Gaussian残差。

比较三条路线：继续放大Full图score，保留表达力但查询图随人口变化；固定潜在支撑图再连续解码，需要新增数据表示与解码验证；采用条件PSD核定义连续的时空Gaussian过程，再叠加逐站轨迹扩散。先执行第三条，利用现有逐站Transformer、S175及真实连续缓存。前两条保留为有针对性的后续对照。

实测细化：主日历seed42的0–50km标准化误差归一化二阶矩由h0的0.657增至h6的0.819，而固定copula约0.338；150–300km的h0为0.076，固定先验约0.242。它支持同时学习相关幅度和随lead变化的相关长度。该量未按条件去均值，不称条件Pearson相关；尺度RMS单列。

## 条件相关核

对查询q及预报时效h=0…6，节点`i=(q,h)`。每个物理起点单独计算：

```
psi_i = [x_q/300km, y_q/300km, z_q/1500m] + 3*tanh(warp(c_i,h)/3)
rho_i = rho_min + (rho_max-rho_min)*sigmoid(logit((rho_ref-rho_min)/(rho_max-rho_min)) + gate(c_i,h))
S_ij = product_d sqrt(2*l_id*l_jd/(l_id^2+l_jd^2))
     * exp(-sum_d (psi_id-psi_jd)^2/(l_id^2+l_jd^2))
K_ij = sqrt(rho_i*rho_j)*S_ij*T[h_i,h_j]
     + 1(id_q == id_r)*sqrt((1-rho_i)*(1-rho_j))*T[h_i,h_j]
```

`rho_min=1e-5`、`rho_max=0.99`是显式模型边界，保证sqrt(rho)梯度与nugget余量；没有添加临时jitter。`rho_ref`分别为现有S175 copula的0.3481921310/0.3618834106。时空warp按h改变位置，可表达随预报时效移动的相关结构；地形、海岸、原生天气与方向通过c_i进入，不增加PWV类变量。

`l_id=exp(clamp(metric[h_i,d],-ln4,ln4))`新增7×3=21个零初始化参数，表示相对300km/300km/1500m基础长度的倍率，按lead学习、两臂相同。天气自适应通过rho、局地warp与T进入。S为单位L2范数Gaussian基函数的内积，不同时效长度变化仍保持PSD与坐标平移不变；不将各lead坐标独立缩放后送RBF，从而避免引入空间原点相关的跨lead距离。metric单独lr1e-3，其他NN为3e-4，两组各按0.1倍最低率的同周期cosine衰减。

天气模式中，`cw90→64→28`输出下三角增量。先取`C0=(T_ref-0.05I)/0.95`的Cholesky根L0；对角`Ljj=L0jj*exp(clamp(delta_jj,-1,1))`，非对角`Lij=L0ij+delta_ij`；令`T=0.95*Corr(L L^T)+0.05I`。非天气模式使用28个全局可学习增量。最后一层/增量初始全零。

核的两项均PSD：归一化Gaussian卷积核与T的Hadamard积，再加按唯一站ID定义的时间块。T含显式5%收缩且rho<0.99，给出SPD余量；不以隐式jitter替代模型。重复坐标、不同ID允许；重复ID拒绝。冻结初始warp/gate/time增量时，K在数值精度内等于原`Ks⊗T_ref`，边际方差为1。

## 查询集合一致性

c175由固定可见站时间编码和逐查询注意力产生；cw与T只由固定可见历史产生；psi/rho逐查询逐lead运算。相同站点/时效在增删其他查询后得到相同K元素，因此新人口K就是原人口K的主子矩阵，Gaussian边际law一致。不同Cholesky根配同IID seed不保证同路径；工程路径检验从共同superset GP样本取子集。

此过程含站ID nugget，解释为观测残差过程。坐标查询连续不等于所有观测噪声具有光滑物理路径。它使用核函数，不要求规则格网。

## 叠加Local轨迹扩散

先冻结获选天气GP。逐查询取7×7边际块的对称根`Aq`，训练目标`zq=u_q*Aq^-1`。从完整GP抽样u0，再逐查询白化得到z0；Local v对每个7维轨迹作用，使用c265。最后`u_q=zq*Aq`，并按原元素尺度恢复mm。

初始Local零速度在Heun0下继承GP样本；GP和逐查询映射均保留查询集合law一致性。Local训练是边际轨迹score，联合相关来自已训练GP与映射；不写成已拟合真实非Gaussian联合field score。与同c265天气GP及同容量逐查询Affine控制比较，才判断非线性扩散的额外作用。
