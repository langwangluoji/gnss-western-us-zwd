# 时空融合与谱残差实验：实现清单

绑定设计：`docs/research_notes/2026-11-25-spectral-diffusion-feasibility.md`及同日masked-transformer规格。用户已授权实现、本机验证和GitHub同步。

## 执行顺序与验收

1. 数学与数据接口：固定锚点H、正定ridge标签编码、固定GFT、训练集标准化/AR创新逆变换；验证缺测、查询分块、折隔离和时间边界。
2. 基础场T0–T5：保留p14参考分支，72h独立窗，16×16因果时空交替，双层空间融合、门控、静态FiLM；验证零初始化与因果性。
3. 概率L/A/B/J：一个创新状态和噪声链，历史谱条件、图谱与双域去噪、频带尺度、未来DCT×GFT分支；验证梯度、采样、逆变换、预测起点。
4. 可执行实验入口：连续小时训练、空间组折外模型、残差生成、表示门槛、同条件Gaussian和diffusion；在真实数据上定位瓶颈。每阶段写机器可读状态和哈希。
5. 绘制实际模块及全流程图、运行测试和独立审阅、提交推送并核对远端SHA。

正式训练默认3000步。工程验证使用显式较短步数，结果称短训；不以短训替代正式年度结论。表示恢复门槛未过时概率分支只允许标记为诊断训练，正式启动应报错。

## 接口核对

- 基础场输出为原归一化surface ZWD；唯一物理反归一化在残差生成处。
- OOF禁止继承已经见过留出标签的权重或统计。全局几何可共享，标签统计按折拟合。
- 概率条件只使用观测及冻结基础场，不使用目标残差历史；AR真实前态只出现在标签变换。
- 同锚点、H、统计和AR的空间/图谱/双域对照才解释为域表示效应。
- J分支的全部动态条件与均值在起点可用，单独登记F预报协议。
