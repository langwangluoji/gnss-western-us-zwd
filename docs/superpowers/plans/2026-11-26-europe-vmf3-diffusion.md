# VMF3-FC接入欧洲基础场＋时空扩散

用户修订：不训练既有CNN，主要将VMF3-FC引入新的扩散融合模型。本合同取代上一方案的CNN重训安排，既有273站CNN结果固定为参考，新增或已中断CNN尝试均保留归档。

## 网络与数据

1. 继承411站、273/64/63/11站址组、2020–2023训练池及2024回看。每条记录6h；16状态90h跨度；未来7输出为0/6/12/18/24/30/36h。
2. 当前基础场采用已完成的VMF3历史GRU校正：p14＋GRU＋I1＋VMF3-FC分支。2023留站监控选择，两个种子均3000连续四记录块。旧基础场与全部科学锁保留。
3. 未来均值沿用已训练欧洲NativeDirectedLagV2的逐时效增量，加当前VMF3校正作为公共偏移；当前输出严格对应新VMF3基础场（浮点转换容差）。这是一种显式冻结的未来锚定规则，未把未来VMF3有效时刻作为条件。
4. 每lead残差按训练统计b/s标准化。概率查询条件218维：原native查询状态64＋原查询条件111＋最终均值7＋VMF3当前三特征/mask4＋已训练VMF3 GRU状态32。全局天气摘要仍用固定可见参考站15维状态，1/4/16记录各均值/标准差，共90维。最后均值显式直连概率模块，补足旧融合接口。
5. 概率链复用现有NativeGaussian、WeatherProjectiveGP的核与相关结构、LocalTrajectoryVelocity/AffineTrajectoryVelocity以及Heun0采样器。欧洲GP适配16记录的90维摘要，不伪造72小时状态；相关保持PSD及单位对角。

## 对照（每种子）

在同一个新VMF3基础场上比较显式VMF3概率条件：

- base：保留native175＋最终均值7，将额外VMF3当前4和GRU32置零。
- vmf：保留全部218条件。
- 每臂各训练Gaussian与天气GP、Local扩散，各3000块；vmf臂另加同预算Affine控制，分离非Gaussian扩散与位置/尺度/线性传输收益。共7模型/种子，两种子。

两臂基础场共享VMF3信息，因此base表示“无额外显式VMF3概率条件”，不是整个系统无VMF3。GP训练仅用几何/固定种子抽32查询，不按未来标签可用性选站；未来mask只用于监督。全部时间块顺序遍历，缺轨迹时记录真实监督计数。

## 评价与收束

2023留站开发用于选择与检查；2024全年回看评价确定性RMSE、当前/+6h及全7lead公平CRPS、80%覆盖、时间增量、近邻站对及场能量评分。K32独立成员、Heun0 20步，与强Gaussian/Affine分别对比。点输出保持冻结新基础场，不把随机成员均值冒充点精度；原始概率中心变化另报告。

残差不是严格折外产生，strict_oof=false；2024已历史暴露。源forecast归档只有有效时刻映射，本轮不宣称逐文件发布时间验证完成的业务实时预报。
