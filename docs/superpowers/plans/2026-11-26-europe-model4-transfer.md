# 欧洲Model4数据上的最佳架构迁移执行计划

用户2026-11-26授权设计并实施；澄清采用相同训练区域和站点，最终比较RMSE，两方法各自保留特征。详细合同、状态和证据位于[实验目录](../../../research/europe_transfer_20261126/README.md)。

1. P0数据合同：读取修复版2020–2023/2024列式HDF5元数据，冻结1km连通站址划分；记录源SHA、真实6h时间、缺测、ZWD米转mm、T摄氏转K和干空气P修正。核验重复键、同址分组和允许列。完成273训练/64开发/63确认/11新站。
2. P1实际架构迁移：复用p14 FixedSupportModel、P14Fusion GRU和NativeDirectedLagV2，不用简化MLP替代。重建欧洲113维点特征、30通道载体、25通道GRU历史及15维逐站状态。先验证隐藏目标/未来扰动不改变条件、411身份索引和有限反传，再真实CUDA四更新。
3. P2正式四年基础场：`train_base --version 2`，seed42/17，各3000连续四记录块。时间按顺序遍历2020–2023，不随机抽时间；条件站抽样且整物理组隐藏目标。2023开发站独立监控选EMA。v1三年阶段保留作诊断。
4. P3正式I1与joint：`native --prepare --version 2`生成固定布局连续段、条件站自创新和查询尺度场；I1仅用训练站标签解析拟合。`native --version 2`逐站因果Transformer各3000块，7输出映射0到36h；跨布局时间连续，所有未来监督不越2024边界。比较点场p14/I1/joint的2023开发站宏RMSE，冻结双种子平均选择。
5. P4原模型：从同273站派生HDF5拷贝，原项目只读。复用FFT-SCHA/CNN-BiLSTM-Attention/XGBoost，保留原年份阶段、特征和默认早停参数，两个种子重训。原模型允许目标站历史，空间场隐藏目标站历史；在最终结果旁披露信息条件差异，不宣称纯结构归因。
6. P5冻结年度评价：`evaluate select`先封存模型与系数哈希，`predict`覆盖2024全部1464历元，`compare`严格对齐共同有效站–UTC键及标签。主人口是63注册确认站，另报开发、新站未见站址及全部留站；micro和站宏RMSE、逐站、月份及双种子等权平均均保留。
7. P6图件和交付：站点地图、全流程架构、训练曲线、最终RMSE、月份曲线和逐站误差地图。核验数据源未改写、重算RMSE、图件实际渲染和代码测试；精确stage轻量文件，提交推送并核对远端HEAD。数据、权重和大型预测数组本地保留。

本轮以用户指定的最终点RMSE为评价目标；美国概率扩散权重不直接迁移。概率分支需在欧洲新残差上另行拟合与校准，本轮不将其宣称为已验证成果。
