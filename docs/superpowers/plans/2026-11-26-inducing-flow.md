# 共享诱导创新流：执行计划与台账

## 目标与依据

承接[潜变量概率流设计](../specs/2026-11-26-projective-latent-flow.md)。旧加法原型已完成真实四更新，但独立潜噪声与零读出使流首步梯度为零。保留旧代码、权重与来源；新增模块实现耦合GP诱导创新。用户已授权持续本机探索及GitHub同步，当前独立研究分支为codex/p14-continuous-fusion。

Ruling：采用R=R_perp+WW^T、xi=epsilon_perp+W eta，再以g(eta)替换eta，保留完整剩余过程。原因是原GP暖启动与首步有效梯度可同时成立；代价为额外小型锚点核分解。不是截断全空间场，也不是传统去噪训练。

## 步骤与验证

1. 数学与模型：先运行缺失模块RED测试；实现确定性几何锚点、精确核分解和耦合解码。验证协方差重建、正定性、查询子集一致、精确暖输出和首步有效梯度。
2. 真实小试：四族affine/odd × time/frequency，同源G265、冻结TF3000均值、冻结S175尺度，CPU各四连续块、K8/Q32。验证同噪声初始损失相同、真实有限标签、首步流梯度、成本与来源。
3. 正式准备：小试通过后核验完整候选与Gaussian对照协议，先做只读独立审阅；登记两种子各3000、主/补充评价规则、全部源/代码哈希与停止线，再启动。不得以小试宣告概率收益。
4. 正式评价：冻结均值，用耦合GP/诱导采样；比较Gaussian、affine和odd，同时考察边际、站对、内部增量、energy及成本。不能直接拼接独立eta与旧GP样本。完成后同步轻量代码、指标、图与协议，权重/数组留本机。
