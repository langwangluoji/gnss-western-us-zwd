# 方法验证规则

## 结论分级

| 等级 | 证据 | 可以说明 |
|---|---|---|
| 工程可运行 | 导入、smoke、单批前向和单元测试 | 代码路径可执行 |
| 本机短训 | 真实数据、固定预算、保存曲线和指标 | 在指定开发合同上出现学习信号 |
| 配对开发实验 | 同数据、同输入、同评价和多种子比较 | 可比较架构或机制 |
| 完整年度/盲测 | 未参与开发的日期、站点和空间区域 | 可报告泛化性能 |
| 服务器规模验证 | 锁定代码、数据、预算和运行回执 | 可报告正式产品结果 |

架构设计、理论推导、网页建议和“任务已启动”都不属于后三类证据。

## 每个实验必须锁定

- 实验编号和目标；
- 数据版本、区域和时间范围；
- 条件站、目标站、确认站角色；
- 输入变量清单和禁止变量；
- 训练/验证/确认划分；
- 随机种子、预算和选模规则；
- 评价日期、布局和查询算子；
- 输出目录、代码哈希和数据哈希。

## 评价最低要求

每个基础场实验至少报告宏 RMSE、微 RMSE、MAE、Bias、P90/P95、站间差值和小时增量 RMSE。生成式实验增加 CRPS、区间覆盖率、空间相关保持率和时间相关保持率。

必须按距离、地形、高程、月份和天气日期分层；时间留出不能替代空间留出。模型选择使用时间监控作为辅助，并检查空间空洞和远距离条件站的误差。

## 数据隔离

目标站标签只能进入损失和评价；条件输入不得读取目标未来值。确认站和原 C/D 标签保持隔离。基础场残差 diffusion 必须使用折外基础场预测构造残差。

## 结果表达

报告明确区分开发回看、短训、完整年度和盲测。保留负结果、失败机制和采样修复记录；不把历史区域或不同输入条件的成绩替换当前研究结果。
