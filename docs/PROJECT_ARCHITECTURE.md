# 项目架构

## 研究层

项目分为四条证据链：

1. **确定性基础场**：背景场、点特征、U-Net 和图空间修正；
2. **生成式场**：条件 Gaussian、GAN、EDM/diffusion 和时序生成；
3. **连续查询与地形细节**：任意查询点、测站高差、空间空洞和多尺度区域上下文；
4. **评价与发布**：站点误差、站间差值、空间留出、时间增量、CRPS 和生成序列一致性。

当前最可靠的架构证据来自 v13：点特征分支与小型 U-Net 空间修正的双种子平均宏 RMSE 为 10.828 mm。它是下一阶段基础场的起点，不是最终生成式模型。

## 数据边界

当前研究区域为美国西部 25–50°N、125–110°W，时间 2016–2020。现有元数据角色为 A174/B511/C110/D110；新的时空扩散协议允许动态轮换条件站和目标站，但必须先完成数据合同。确认站和原 C/D 标签不得被开发实验读取。

新模型只可使用与 GNSS 站点一致的气象变量、ZWD 历史、地形和空间支撑特征。PWV/IWV/TCWV/Tm 不得作为条件或教师。历史制包曾使用 PWV 完整率筛选，这一来源限制必须在报告中披露。

## Git 边界

同步 GitHub：代码、配置、协议、轻量指标、曲线、报告、来源和哈希清单。留在本机：原始观测、唯一权重、预测数组、缓存、临时训练日志和凭据。每次变更完成测试或审计后提交并推送，核对本地 HEAD 与远端 main 一致。
